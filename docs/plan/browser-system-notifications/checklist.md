# 验收清单

- [x] Local/Desktop/Compose/默认模式 browser feed 与回执正常；local 原限制保留。
- [x] 匿名请求 401、跨用户 feed 为空、跨用户回执 404；重复回执幂等。
- [x] 全局关闭后 pending 被跳过，旧回执 409，再开启不补发关闭期间通知。
- [x] 标题与实际结果摘要一致；拒绝跨用户、非 pending、无效 ID、超过 200 字符正文。
- [x] 授权只通过用户点击；拒绝、未授权、不安全来源、无 Web Locks 不展示、不报成功。
- [x] 同浏览器多个消费者去重；已展示未回执重启仅补交回执；submitting 不重弹。
- [x] 存储损坏/不可写安全停止；无 show 不提交 delivered。
- [x] 后台页面继续轮询；退出/换号/迟到响应和页面缓存恢复有测试。
- [x] 文件 SQLite 与 PostgreSQL 通知回归、Electron 通知回归。
- [x] 真实 Chromium 双标签页只提交一次、关闭展示标签页后不重复。
- [x] 前端发布构建、受影响文件 lint、接口生成检查。
- [x] Safari Local 实际触发网站授权弹窗，允许后两条真实通知各有一次 delivered 回执；真实 feed 返回已认证用户 ID。
- [ ] macOS 真机在网站/系统允许通知后，页面最小化时实际看到结果横幅及通知中心记录，点击打开任务结果。
- [ ] Windows 通知中心、Safari/Firefox 浏览器真机确认。

人工验收：启动 Local（或部署 HTTPS Compose）后登录，进入通知设置并点击“允许系统通知”；在浏览器弹窗允许，macOS 系统设置中允许对应浏览器通知。创建短周期定时任务，开启系统通知及成功事件，打开两个同源标签页，最小化浏览器，等待任务完成。核对只有一个系统通知、标题/摘要正确，点击定位结果。再检查总开关关闭、网站拒绝权限、关闭一个标签页、退出登录的行为。关闭全部页面后不要求通知；无 Web Push。
