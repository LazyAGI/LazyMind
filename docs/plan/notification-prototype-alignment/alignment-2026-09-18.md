# 通知前端原型核对（2026-09-18）

## 参考来源

用户提供的四份本地 HTML：lazymind-notifications-v8.html、lazymind-default-connections.html、lazymind-default-notifications.html、lazymind-default-scheduled-task-notification.html。逐文件比较确认仅初始页面/默认打开通知抽屉不同，页面实现相同。飞书文档本轮无法直接访问，未声称已读取在线最新附件。

原型中的演示数据、模拟扫码、说明弹窗不作为生产行为。企业微信沿用用户已确认的 BotID + Secret 智能机器人授权；飞书保留机器人复用及明确的新建操作。

## 页面与交互对应

| 原型页面 | 生产实现及本轮调整 |
| --- | --- |
| 终端连接 | 复用 TerminalConnectionPage；三平台选项、账号管理与连接双栏、连接标题与品牌、扫码准备/过程中/成功失败状态；保留真实账号、默认接收对象、重连解绑及删除接口。无已有机器人时不重复出现“新增机器人”按钮。 |
| 消息通知 | 复用 NotificationSettings/RuleEditor；全局开关、四渠道、未连接外部渠道提示、默认事件及“仅新任务”标识。 |
| 新建/编辑定时任务 | 复用 ScheduleList；任务/任务组选择、表单间距、固定标题与底栏、表单内滚动、标题通知入口、紧凑通知摘要。 |
| 执行时间 | 增加工作日/每天/每周快捷选项，保留自定义周/月间隔；不改写未操作的既有自定义时间。最后一个选中星期不可取消，避免变成每日执行。 |
| 任务组管理 | 默认显示全部任务，组统计基于完整任务列表，空组保留查看与删除入口；空组查看后可添加任务并预选所属组；任务更多菜单可选择分组或移到“其他任务”；切换任务/任务组保留组草稿。设置页入口明确为“管理任务与任务组”。 |
| 任务卡片操作 | 配置通知、立即执行、更多操作固定组合；更多菜单保留编辑、分组移动和删除，去除重复的配置通知菜单项。 |
| 单任务通知 | 复用 ScheduleNotificationPanel；概览卡片、事件与渠道区域、底栏默认规则/取消/保存；修正任务弹窗→通知抽屉→设置/连接→接收对象的覆盖层级。 |
| 任务详情与通知记录 | 复用既有任务详情、ConfiguredChannel 和 NotificationHistory；保留真实历史快照、重试幂等和发送状态逻辑。 |

HTML 对任务组创建/删除只给出演示提示，本轮复用已有真实管理接口，没有建立另一套模拟任务组。

## 验证

- 通知、连接、草稿、接收对象、任务列表、设置列表及调度选择器相关回归测试。
- 新增：频率切换保持时刻、自定义月度周期不被改写、最后一个星期保护、空组可管理并预选组创建任务。
- Chrome 独立浏览器上下文以模拟 API 渲染真实组件，检查连接、企业微信授权表单、通知设置、通知抽屉、任务组列表、任务/任务组创建。
- 1280×900 和 820×650 窗口检查；小窗口保存按钮在可视区域内；浏览器无页面脚本异常。模拟请求未访问真实业务数据，也未发通知。
- 前端生产构建及 git diff --check。桌面安装包需单独重建才能包含本轮前端修改。
