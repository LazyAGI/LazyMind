# 通知原型对齐

用户已依据前端核对报告要求修改；沿用此前直接实现后统一测试的明确要求。范围为核对报告中的新建/编辑通知草稿、原子保存、清除配置、配置入口、布局、详情摘要、按运行状态确认、连接返回和品牌信息。复用现有通知组件、账号接入、校验与事务，不新增依赖或数据库迁移。

创建和更新任务新增可选 notification 对象，包含 config 或 clear:true；编辑需传已有 revision。省略时保留现有创建默认/编辑不变行为。独立通知 PUT 增加显式 clear:true，不能与 config 同传。冲突409且任务和规则均不保存；清除不改变运行快照和历史。

保留企业微信 BotID＋Secret、微信 iLink、浏览器和 Desktop 通知，以及旧任务未配置状态。既有时间控件、多依赖能力不缩水。
