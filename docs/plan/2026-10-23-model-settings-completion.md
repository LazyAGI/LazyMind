# 模型配置页完整配置与中英文体验

**目标：** 在已确认的 Cherry Studio 风格供应商双栏布局上，完成模型页的配置流程、清晰反馈和中英文展示；继续在主工作区 `feat/chat` 实施。

**架构：** 供应商技术身份、原始模型类型和持久化引用保持不变。展示名称集中本地化；模型编辑通过现有 PATCH 路由的可选字段完成，目录模型须显式转为自定义覆盖。类型与引用校验在供应商锁内重读，和默认模型、固定会话写入使用相同锁序。

**技术：** React 18、TypeScript、Ant Design 5、i18next、Go/GORM、OpenAPI；合成 Vitest/Go 回归与实际浏览器验收。

## 完成要求与证据

- [x] 名称：中文界面使用深度求索、豆包、智谱、月之暗面、通义千问、商汤日日新、硅基流动；英文品牌保留英文，英文界面使用英文名称。用户自定义名称保持原样；展示名称不写回 API。
- [x] 搜索：供应商和默认模型选项支持中英文及既有品牌别名。真实 i18next 切换和 API 身份不变有回归。
- [x] 完整模型编辑：模型 ID、真实类型、LLM/VLM 上下文、LLM 视觉能力；目录覆盖显式保存为自定义，UUID 和兼容引用不变。失败保留草稿，提交期间禁止重复保存或关闭。
- [x] 后端保护：新增/编辑拒绝未知和协议不兼容类型；在用的默认、固定会话、向量索引不能被元数据修改破坏。检查新增、固定修改、分叉和侧聊入口，并做交错请求回归。
- [x] 模型同步：仅显示有数据的任务类型，搜索不改变分类入口与计数；自定义分区有短标识；已知不兼容类型不能单项或批量添加，未知类型仍须明确选择。
- [x] 配置反馈：模型加载失败可重试并保留缓存，不能假装没有模型；慢 GET 不能覆盖成功增删改；新增失败保留输入并显示本地化错误。
- [x] 供应商细节：未保存地址在手机返回时有保护，空兼容记录不计作已配置，名称按后端 UTF-8 字节限制校验，切换模板保留用户输入地址。
- [x] 视觉：保持紧凑双栏与彩底类型图标；长供应商名称省略并可查看全文；模型 ID 支持键盘/触摸披露，类型筛选支持键盘导航。
- [x] i18n：新交互完整中英文，中文模型页统一“API地址”“API 秘钥”，无新增技术占位标签或未翻译 key。
- [x] 回归：模型/设置完整前端测试、后端模型/聊天/凭据/默认/错误目录测试、生成物检查；同依赖 TypeScript 基线比较，不将全仓既有诊断称为通过。
- [x] 收尾：独立 Bug 自检和无效代码清理，复审本轮完整补丁及 P0/P1；构建并启动前后端，实际桌面/手机和中英文验收，再提交和核对工作区。验证细节见同目录 `2026-10-23-model-settings-review-results.md`。

## 测试与验收命令

前端：`pnpm exec vitest run src/modules/modelProvider src/modules/settings --minWorkers=1 --maxWorkers=3`；`pnpm exec tsc --noEmit --pretty false`；`node scripts/openapi/check-stale.mjs`；`node scripts/i18n/sync-error-codes.mjs --check`。

后端：`GOMAXPROCS=3 go test -p 2 ./modelprovider ./chat ./modelconfig ./credentialvault ./externalcapability ./common`；引用交错与元数据回归另做定向 race 检查。

实际界面：不调用真实付费模型，不修改用户秘钥、默认模型或索引。检查 1440/900/390px、图标加载、中文默认供应商/英文品牌/用户自定义名称、真实模型读取和同步侧栏；新增/编辑/失败交互使用隔离浏览器合成 API 响应验证。
