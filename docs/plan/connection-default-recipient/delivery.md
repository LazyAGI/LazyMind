# 连接默认接收对象修补

## 实现

复用现有连接表、接收对象表、所有者校验、凭据存储、飞书官方 SDK 及渠道发送链路。接收对象选择器从任务编辑器抽出，供任务规则、连接详情和扫码成功后的入口共用。连接默认值独立保存，已有任务固定目标与历史快照不改写。

增加飞书机器人的群候选分页、真实群名称、保存和发送前的机器人群成员资格校验；保持群对话关闭。权限不足时显示可操作提示，已有私聊目标仍可选。群名称相同时追加对象 ID；默认群不在第一页时按 ID 读取。

新增 API 使用生成客户端。共享 ID 校验支持现有渠道标识（含微信 `@`），目标必须存在于当前账号。保存基于凭据版本校验，防止授权变化期间写入过期群信息。

SQLite 与 PostgreSQL 增量升级保留旧记录，新默认值为空；没有新生产依赖、服务、数据重置或 Git 提交。

成员资格校验改为重新读取应用身份的机器人所在群列表，复用既有只读权限与分页实现，不使用缓存作为资格证明。完整列表未找到返回 422；权限失败、游标循环、扫描页数/时间上限返回 503，安全失败。最多 20 页，15 秒预算（单请求 SDK 超时 10 秒）。不新增权限、不开放群对话。
