## 人工验收（使用已有验收资料）

1. 打开桌面版「连接管理 → 飞书」，展开目标机器人，确认授权人、应用 ID 与要加入群的机器人一致。
2. 在飞书把这一个机器人加入目标群。在连接记录点击「选择默认接收对象」，刷新后选择真实群名称并保存。若提示读取失败，检查该机器人的群信息只读权限，必要时由本人完成重新授权。
3. 刷新页面，默认对象应保持；新建任务或给未选对象的任务选择此连接，接收对象应带入该群。
4. 把连接默认对象改为另一个群：已有任务配置应仍指向原群。新选连接的任务采用新默认值。
5. 清除默认对象后再次选择连接，应要求手动选择，不自动选首项。
6. 将机器人移出测试群，保存该群为默认对象应失败；通知发送也必须拒绝该对象。验收完成后由本人按需恢复机器人入群。
7. 如需真实发送验收，由本人执行一个已配置测试任务，检查目标群收到一次结果通知，其他群不收到。

不替用户发送外部测试消息，不自动新增飞书授权；真实群权限与实际消息到达仍需本人确认。
