# 连接默认接收对象

用户确认按原型修补，沿用此前“直接实现、最后测试”的要求。每条连接独立保存一个默认接收对象；飞书提供机器人所在群的分页候选与真实名称。扫码成功后提示选择默认对象，允许之后修改或清除。新连接不替换其他连接或已有任务。

任务配置在选择连接时带入其有效默认对象，保存具体 account_id + recipient_id；已有对象不被后续默认变化覆盖。默认为空时不猜测首项；旧 primary_recipient 字段保持兼容，新 default_recipient 明确表示用户保存的默认值。现有任务引用和通知快照不改。

飞书群发现使用应用身份和只读群信息权限，保存及投递前验证机器人仍在群内。只增加通知发送目标，不启用群内对话或放开群成员调用。其他渠道继续使用既有可用会话和验证路径，不假定微信或企微具备飞书群发现能力。

持久化复用账号与接收对象表，只增加默认 ID、展示名称和对象类型；SQLite/PostgreSQL 各自增量初始化。不删除数据、不新建服务或生产依赖。SDK/API失败只返回稳定安全错误；既有未授权机器人提示重新授权，由用户实际完成，不替用户批准新增平台权限。
