# 供应商优先的模型设置

本阶段按 2026-10-22 最新确认实施：在主工作区 `feat/chat` 合入 `origin/main`；参考 [Cherry Studio 模型服务设置](https://www.cherryai.com/docs/en/pre-basic/settings/providers/)重做紧凑双栏布局。此前计划中“按协议合并连接、不同地址迁移为新供应商”的方案已由以下边界取代。

## 最新边界（取消连接实例）

- 内置供应商与自定义供应商都在左栏。自定义供应商允许添加、改名、修改端点和删除；名称与运行协议分开保存。
- “模型服务”和“默认模型”是设置中的两个独立入口。默认模型使用单独页面，旧 view=defaults 或 target 深链继续可用。
- 所有自定义供应商（包括旧页面迁移的配置）使用统一的中性默认图标；内置供应商保留品牌图标。聊天模型列表返回自定义身份和显示名称，技术协议字段继续供运行时使用。
- 模型配置直接属于供应商，页面不再显示连接实例、分组、连接数量和无助于操作的说明文字。存储保留一个私有兼容组以维持模型 ID、密文和凭据绑定。
- 每个供应商仍最多启用一个 Key；可保存其他停用 Key。切换先验证，停用或删除后不自动启用替代项。
- 旧组改过名称或端点的迁移为独立自定义供应商，多余的同名组也拆成独立供应商，保留所有模型和 Key。若没有后续端点修改，用上次端点迁移备份恢复各自原地址；否则保留后续用户修改。
- 内置供应商恢复目录地址。迁移只改变归属，不改变原组/模型 ID、默认模型引用和密文；已明确停用的 Key 不重新启用。地址或凭据归属不能证明有效时要求重新检查。
- OCR、搜索等非模型服务保留原配置。构建期模型目录、彩标和默认禁用硬编码的策略保留。
