# 供应商优先的模型设置

模型配置采用供应商优先的紧凑双栏，参考 Cherry Studio 的模型服务交互，使用本项目组件实现。模型相关改动独立保存在 `codex/model-settings`，基线为 `31eefd20`；原实现保存在 `feat/chat` 的 `436a6405`。

## 页面与数据边界

- 内置和自定义供应商位于左栏；多套餐品牌父层只展开/收起，子服务才切换配置。自定义供应商支持添加、改名、修改 API地址和删除；显示名称与运行协议分别保存。
- “模型服务”和“默认模型”是设置中的两个独立入口；旧 `view=defaults` 和 `target` 深链继续可用。
- 迁移得到的供应商与用户新建供应商使用中性模型图标，支持上传供应商 Logo；内置供应商保留品牌图标，品牌不随请求协议变化。
- 页面取消连接实例、分组和连接数量。存储保留一个私有兼容组以维持模型 UUID、密文和凭据绑定。
- 每个供应商最多启用一个 API 秘钥，可保存其他停用秘钥。保存、替换、启用与连接验证解绑；停用或删除后不自动启用其他项。
- 旧组名称或地址有定制时迁为独立自定义供应商，多余同名组也拆开，保留模型、秘钥和默认模型引用。无法证明验证状态仍有效时要求重新检查。
- OCR、搜索等非模型服务沿用原配置；构建期上游目录及默认停用硬编码目录的策略保持。

## 配置交互

- 模型服务嵌入原设置内容区，导航持续可见。自定义供应商及其自定义模型稳定置顶，不改变默认模型选择。
- API 秘钥支持复制、替换、显示/隐藏、删除和右侧管理面板。只有明确操作才读取所选明文；切换供应商、关闭管理或替换后清理显示值。明文不写入 URL 或本地存储。
- API地址旁打开请求配置侧栏，分别配置 OpenAI/Anthropic 地址和默认协议。留空使用默认地址；实际变更撤销过期验证，无变化保存保留原适配器及有效检查。
- Anthropic 仅支持现有聊天/视觉类型；切换会影响非兼容模型时拒绝保存。尚无运行时适配器的 Gemini、OpenAI Responses 明确禁用。
- 同步模型侧栏提供搜索、任务分类、折叠分区、逐项/整组/全部添加或移除。远端拉取只读取，不自动导入；已添加项浅绿显示，目录外模型明确标记。
- 远端失败不等同于模型失效；逐项加减直接执行，侧栏提供“添加全部模型”和“移出全部模型”，批量移出不受筛选限制。未知类型可保存到库存，补全类型前不能测试或运行；无运行时适配器的类型禁止添加为可运行配置。
- 模型行保留品牌 Logo、彩底任务标记、完整 ID 提示及编辑入口。编辑支持模型 ID、真实类型、LLM/VLM 上下文和 LLM 视觉能力。
- 目录模型通过显式自定义覆盖修改，保留 UUID；校验默认模型、固定会话和向量索引引用，禁止不兼容修改。

## 模型迁移和运行时

模型分支保留以下可逆迁移及对应 aggregate 更新：

| 迁移 | 用途 |
| --- | --- |
| `20261022060632` | 供应商共享 API地址及兼容组镜像 |
| `20261022065811` | 同供应商单个启用秘钥及选择版本 |
| `20261022072824` | 旧连接拆为自定义供应商，保留模型和凭据身份 |
| `20261022092432` | 供应商请求协议及地址配置 |
| `20261023032750` | 模型上下文、最大输入与输出 Token 上限 |
| `20261023104231` | 自定义供应商 Logo |

迁移和恢复不得泄露明文、丢失秘钥、改变模型 UUID 或绕过用户归属。端点、启用项、请求配置和加密备份共同维护相同供应商边界；恢复不能重新引入连接级端点或错误启用第一条秘钥。

Go、Python/OpenCode 运行时只接收启用秘钥。旧换行格式保留完整秘钥池，按供应商保存的活动项选择运行秘钥；加密备份保留完整秘钥池，并通过活动索引恢复相同选择。秘钥选择变更使用 revision 防止慢请求或旧上传任务覆盖较新选择。

## 历史验证与重新验收

以下仅是拆分前模型实现的验证证据，独立分支的结果另行记录：

- PostgreSQL/SQLite 的模型迁移执行过 up/down 与 aggregate 一致性检查，旧模型 ID、凭据密文和默认选择保持。
- `modelprovider`、`credentialvault`、`modelconfig`、`chat`、`externalcapability` 相关回归以及 OpenAPI 契约和生成物检查通过。
- 前端模型页、默认模型和设置入口有组件及集成回归；最新历史模型/设置完整套件为 77 文件、661 项通过。
- 实际 1440/900/390px 页面检查过导航内嵌、供应商列表、默认模型独立入口、秘钥管理、请求侧栏与模型同步；页面无横向溢出，Logo 正常加载。
- 显式布尔化加载标记，修复 Ant Design Spin 在请求完成后保留遮罩的问题，并增加回归。
- 全仓 TypeScript 仍有既有诊断，没有将全仓检查描述为通过。

新分支验收须重新核对纯模型 diff、共享文件、生成物、迁移和相关测试；历史容器及浏览器结果不自动等同于拆分后部署结果。更多模型实现证据与限制见 [模型配置验收记录](2026-10-23-model-settings-review-results.md)。
