# 实施任务

1. 备份原工作目录已提交历史、未提交差异和未跟踪文件；保存 SHA-256 清单。
2. 获取官方 main，建立独立 worktree `codex/notifications-official-main`，固定基线提交。
3. 拆分通知提交与后续修改，排除工作区生产改动、测试和无关 review 文档；按原有审查范围复用实现与测试。
4. 手工处理官方更新造成的六处重叠：迁移清单、aggregate、OpenAPI、桌面主进程、连接页和定时任务设置页；保留官方新增功能。
5. 执行文件 SQLite/PostgreSQL Core 和 Gateway、通知并发 race、桌面、CLI、运行管理器、Python 启动、前端验证；独立官方副本核验失败来源。
6. 按用户最终决定保留官方既有失败，额外 SQL 和 mock 修复不实施；仅完成分支隔离与交付。
7. 重建 macOS 桌面包，验证签名与包内资源，记录启动及人工验收边界。
8. 审核最终差异、提交并上传新功能分支；核验远端提交与基线。
9. 确认新交付完成后删除旧通知分支；原目录保留为未提交改动备份，不碰其他功能分支。
