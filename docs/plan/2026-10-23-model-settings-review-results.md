# 模型配置页验收与复审记录

日期：2026-10-23。独立模型分支：`codex/model-settings`；基线：`31eefd20`。原实现保存在 `feat/chat` 的 `436a6405`。

本文只记录模型配置、凭据、运行时和相关迁移。历史测试与浏览器结论来自拆分前的模型实现，不能替代独立分支重新验收；拆分后结果另行追加。

## 模型实现范围

| 要求 | 已实现行为 |
| --- | --- |
| 供应商与默认模型入口 | 供应商位于左侧紧凑双栏，模型服务与默认模型是设置内两个独立入口；兼容旧深链。 |
| 中文名称和英文品牌 | 中文界面使用深度求索、豆包、智谱、月之暗面、通义千问、商汤日日新、硅基流动。OpenRouter 等英文品牌和用户自定义名称保持原样；展示名不写回 API 身份。 |
| Logo 与任务类型 | 品牌不随协议变化，自定义供应商使用中性模型图标；模型行左侧品牌 Logo，右侧单个彩底任务标记。自定义供应商和自定义模型优先。 |
| 秘钥及请求配置 | 每个供应商最多启用一个秘钥，提供复制、替换、显隐、删除和管理侧栏；统一 API地址，支持已接入协议的独立地址和默认协议。 |
| 完整模型编辑 | 支持模型 ID、真实类型、LLM/VLM 上下文和 LLM 视觉能力；目录覆盖显式转为自定义并保留 UUID；失败保留草稿，保存期间防重复提交和关闭。 |
| 引用和并发保护 | 新增/编辑验证类型及协议，默认模型、固定会话、侧聊和分叉写入时在供应商锁内重读；阻止破坏引用的修改，删除也按锁内当前类型执行确认及清理。 |
| 同步模型 | 只显示有数据的任务类型；搜索不改变入口计数；已知协议不兼容类型禁止添加，未知类型需明确选择，保留目录外模型和自定义分区。 |
| 错误和慢请求 | 加载失败可重试并保留缓存；旧 GET 不覆盖成功增删改；服务器 model_count 支持未访问但已有模型的无秘钥供应商出现在已配置列表。 |
| 中英文文案 | 主模型流程统一“API地址”“API 秘钥”，新表单、错误和侧栏提供中英翻译与无障碍名称。 |

- 分别进行 Bug 自检和无效代码清理，修复显式关闭视觉能力被上游目录覆盖、未加载模型供应商漏筛等问题；删除失去最后引用的十条翻译。

- 秘钥选择变更同事务增加 revision、重加密并进入备份队列；旧 outbox 任务按 revision 收尾，避免覆盖上传期间产生的新选择。
