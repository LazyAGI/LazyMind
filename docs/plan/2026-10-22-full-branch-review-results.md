### 1. 恢复凭据后错误启用第一条 Key

原备份只保存 Key pool，没有保存启用选择或显式停用状态；在新安装恢复时会自动启用第一条 Key。

修复在加密 payload 中保存可移植的 Key 索引，明确区分旧备份、停用、选中某条 Key。恢复新 group、替换、另存和临时恢复都保留正确选择。选择变更在同一事务中提升凭据 revision、按新 AAD 重加密并排入备份；outbox 完成、重试、丢弃和冲突处理使用 revision 条件，保留上传期间产生的新选择。

回归涵盖第二 Key、停用、旧备份、非法索引、实际加密往返、新 group、替换/另存、临时恢复、revision 和旧上传收尾。完整包测试及定向 race 检查通过。新版兼容旧备份；新版 metadata 需要新版应用读取。

### 2. 共享部署可访问宿主用户的本地 Zotero

原本有自己论文库写权限的普通账号可请求本地来源，间接读取服务器宿主用户免密的 Zotero API。

共享模式现在在任何联网之前拒绝本地来源。可信本地运行时还须配置初始化管理员用户名，并将真实 Bearer 发送给认证服务重新校验用户 ID、用户名和当前管理员角色；身份头和转发头不能代替认证。认证故障安全失败，云来源重定向及实际 DNS 解析继续拒绝私网目标。桌面运行时已有的初始化账号和自动登录契约保持兼容。

合成回归涵盖共享部署零联网拒绝、伪造身份、普通用户、其他管理员、过期令牌、认证故障、重定向和私网目标；未读取真实 Zotero。
