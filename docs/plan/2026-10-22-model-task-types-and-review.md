# 模型任务类型、彩底图标与审查

**目标：** 在模型设置中按实际任务分类，使用彩底 SVG；完成 Bug 自检、无效代码清理和模型相关 diff 审查。

**架构：** `modelTaskTypes.ts` 只负责展示归类。LLM/VLM、文本/多模态向量等运行时子类型保持区分；已支持的技术别名可以规范化。类型图标与模型品牌 Logo 独立，已配置列表和同步侧栏共用类型标识。未知类型必须明确选择后添加，不根据输入/输出模态推断调用类型。

**技术：** React、TypeScript、Ant Design、i18next、SVG；验证使用 Vitest、Go/Python 回归和实际浏览器。

## 独立分支范围

- 模型分支：`codex/model-settings`，基于 `31eefd20`。
- 本文只覆盖模型分类、图标及相关配置行为。原实现保存在 `feat/chat` 的 `436a6405`；下述历史验证不替代独立分支的重新验收。
- 任务类型：对话模型、向量化、重排序、语音识别、语音合成、图像生成、图像编辑、视频生成。
- 预留图标：实时语音、文档解析、内容审核；运行时未接入前不作为可选类型。
- LLM/VLM/自进化展示为对话模型，文本与多模态向量展示为向量化，保存与调用仍使用真实技术类型。
- 模型左侧保留品牌 Logo，右侧显示单个彩底任务标记。视觉、推理、工具等细节保留在详情中。
- 保留自定义供应商中性图标、自定义置顶、单个启用 Key、验证门禁、草稿提示和嵌入模型删除影响确认。
