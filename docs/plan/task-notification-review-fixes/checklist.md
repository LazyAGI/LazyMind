## F4 重试链

- [x] 真实 HTTP：原通知 failed → 重试子记录 unknown → 再点击 failed 祖先且不确认；返回 409 `NOTIFICATION_CONFIRMATION_REQUIRED`，新增记录数 0。
- [x] 明确确认后恰好创建 1 条新尝试，不修改任务结果或原历史；检查点来自有效尝试，已确认分段不重复发送。
- [x] 链中 queued/sending 时不同 key 返回 409 `NOTIFICATION_STATE_CHANGED`；链中 sent 后再次点击失败祖先也返回同错误。
- [x] 相同原记录和 key 的并发/后续回放返回同一记录；不同 key 并发只允许一条新活动尝试。
- [ ] 多层祖先、历史分叉、相同时间戳和其他通知链均被正确识别；未知分支风险不能通过选择失败记录绕过。
- [ ] 总开关关闭为 409 `NOTIFICATIONS_DISABLED`，目标失效为 422 `NOTIFICATION_TARGET_UNAVAILABLE`；不存在或跨用户记录为 404 `NOTIFICATION_NOT_FOUND`。
- [x] 原历史、渲染分段、已确认进度、Provider 状态及审计关联不被改写；现有聊天 Outbox 回归通过。
- [x] 未提供确认时默认 false；操作 key 保持 1—128 字符；不增加新的生产阈值或重试队列。
