# 验收标准

- [x] 单次重跑同样失败，实际错误为 HTTP 500 / 2001405，尚不能归因于并发。
- [x] 只读确认当前模型密文 1 条：Local 默认密钥可读 1 条，桌面密钥可读 0 条。
- [x] 测试使用文件 SQLite 与合成凭据，复现不同密钥无法读取同一密文。
- [x] dry-run 不改写数据/配置，不创建备份；准确报告需恢复和已匹配数量。
- [x] apply 前验证运行状态 stopped、无活动进程；未知状态也拒绝。
- [x] 备份可读取原数据及配置、设备身份；备份目录和文件无组/其他用户访问权限。
- [x] 仅重新加密源密钥密文，目标密钥密文原字节保留，其他字段/业务数据保持不变。
- [x] Local 配置中目标密钥只出现一次，权限 0600，其他设置保留，Git 忽略保持有效。
- [x] 第二次执行变更数为 0，密文和 Local 配置保持原字节。
- [x] 错源密钥、空源密钥、缺失/无效身份、未知/损坏密文、冲突配置及配置符号链接均安全失败。
- [x] 数据库写入中途失败时所有记录与 Local 配置回滚，错误不泄露模拟凭据或密钥。
- [x] CLI 默认只读且输出脱敏，备份故障/配置故障拒绝写入，两种中断状态均可继续恢复，SQLite 备份包含 WAL 中已提交的数据（25 项场景及相关包 race 测试通过）。
- [x] 真实恢复前停止相关服务、检查零活动任务；通过已有命令启动，模型请求不再报 2001405。
- [x] 桌面执行现有验收任务成功；切换 Local 后同样成功；再切回桌面成功。
- [x] 记录通知实际投递情况、备份路径和未验证边界。

本维护工具只覆盖显式指定的本地文件 SQLite；没有 PostgreSQL Schema、迁移或 API 修改，不代表完整 Compose 验收。

记录说明：幂等、拒绝、回滚和中断恢复由自动化测试验证；实际环境执行一次 apply。通知仍为 pending、无桌面回执，界面显示“等待交接”并出现通知记录加载失败；勾选“记录通知实际投递情况”不表示横幅验收通过。
