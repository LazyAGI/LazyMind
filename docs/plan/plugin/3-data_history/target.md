# 阶段 3：数据历史与富媒体支持

> 在已打通的插件执行管道基础上，补齐 artifact 的持久化版本历史、富媒体输入输出、跨步骤引用与前端展示能力。

---

## 一、Artifact 序号与顺序管理

1. **Seq 由框架自动分配**：同一 slot 内每次新增 artifact 时，seq 由服务端单调递增分配，不依赖大模型计算；seq 一旦分配不可复用（即使对应 artifact 被删除）。
2. **顺序语义可配置**：在 `plugin.yaml` 的 slot 定义中支持声明该 slot 的 artifact 顺序是否有意义（如 ppt 场景的页面顺序 vs 素材收集的无序列表）；有序 slot 支持前端拖拽调序并持久化。
3. **逻辑删除**：artifact 删除后在数据库中标记为隐藏而非物理删除，seq 不变，前端不展示；用户后续引用"第N个"时，以当前可见序列的第N个为准。

## 二、外部数据输入

4. **联网搜索结果入库**：SubAgent 通过联网搜索工具获取的图片、文件等结果，可通过 `save_artifact` 存入对应 slot；前端 Plugin Panel 按 slot 类型正常展示（图片缩略图、文件下载等）。
5. **知识库检索支持**：SubAgent 可列出当前用户有权访问的知识库（含名称、类型、标签），并从指定知识库中检索相关内容作为步骤输入。
6. **用户上传附件传递**：用户在对话框中上传的图片或文档，可以作为当前步骤的输入传递给 SubAgent；ChatAgent 在意图识别时也能感知到这些附件。

## 三、用户标注与意图理解

7. **前端标注传递**：用户在 Plugin Panel 中对某个 artifact 做的标注（如选中、高亮、批注），应能传递给 ChatAgent 用于意图判断，也能传递给 SubAgent 用于执行时定向修改。
8. **"第N个"意图解析**：当用户提及"第N个"、"最后一个"等相对引用时，ChatAgent 应基于当前可见的 artifact 列表（排除已删除项）正确解析指代目标；系统需向 ChatAgent 提供可见 artifact 的序号映射关系。

## 四、上下文携带

9. **对话历史与 artifact 上下文**：每轮对话时，ChatAgent 应能获取当前插件会话中各步骤已产出的 artifact 摘要（非全量内容），以便在多轮交互中保持上下文连贯；摘要粒度可由 `plugin.yaml` 配置。
10. **图片 artifact 附描述**：图片类型的 artifact 写入时支持附带文字描述；描述作为摘要在后续步骤的上下文和意图识别中使用。

## 五、Artifact 类型与渲染

11. **动态类型推断**：artifact 的 `content_type` 支持在运行时由 SubAgent 根据实际产出决定（而非完全由 state.yml 静态声明）；对于 N 选 1 的类型（如某步骤可产出图片或 HTML 代码），框架应能正确分发到前端对应渲染器。
12. **跨步骤联合渲染**：Plugin Panel 支持将多个 slot 的内容组合在同一视图中展示；例如 ppt 场景下，每一页的描述、图片（或 HTML）和讲稿作为一行并排呈现，支持整体调序。

## 六、版本历史

13. **版本历史粒度**：版本历史以 `(artifact_key, seq)` 为单位，即 slot 中每一条具体内容项各自独立维护版本历史；同一 key 下不同 seq 的内容互不干扰。
14. **线性版本历史**：每个 `(artifact_key, seq)` 条目支持版本历史；AI 每次写入和用户每次人工修改都追加一个新版本，版本列表保持线性顺序；回退到某个历史版本后，该版本成为新的当前版本，不产生分叉。
15. **AI 写入快照时机**：AI 生成时在整个步骤完成后打一次快照，流式输出过程中不逐 token 打快照。
16. **人工编辑快照**：用户在 Plugin Panel 内直接编辑某条内容时，连续编辑合并为一个版本（防抖处理）；用户发送下一条对话消息前，强制保存当前编辑，确保版本连续。
17. **大内容外部存储**：内容超过一定大小时存入对象存储（OSS/S3），数据库字段存储引用地址，对上层透明。
18. **版本管理 API**：支持查询某条内容的当前（HEAD）版本、查看该条目的版本树结构、将 HEAD 回退到任意指定版本。
19. **前端版本历史面板**：以树形或列表展示某条内容的版本历史，支持点击预览任意版本；支持版本对比（文本行级 diff，图片并排对比）；支持一键回退到选定版本。

## 七、跨面板引用

19. **图片引用到对话框**：用户可在 Plugin Panel 中对某张图片点击「引用」，将该图片作为附件注入对话输入框，随下一条消息一起发送，供 ChatAgent 和 SubAgent 感知。

## 八、国际化

20. **插件 i18n 支持**：`plugin.yaml` 中的插件名称、步骤标签、slot 标签等展示文案支持多语言配置；前端 Plugin Panel 按当前界面语言自动切换对应文案。
