# 生词同步到欧路词典与墨墨背单词

在「云文档」中找到与其他服务并列的「欧路词典」和「墨墨背单词」卡片，点击配置入口填写各自的个人 Token。可以只启用一家，也可以同时启用。

1. 欧路：登录 https://my.eudic.net/OpenAPI/Authorization 获取个人授权信息。墨墨：App「我的 → 更多设置 → 实验功能 → 开放 API」获取 Token。
2. 填写 Token 并验证连接，选择目标词本；只有一个词本时自动选中。需要新词本时再展开创建操作。
3. 保存并启用连接。连接完成后显示已保存的目标词本和真实同步状态，自动同步开关单独保存，失败时保持原状态。更换 Token、新建词本、学习计划和历史同步位于展开设置中。保存后的 Token 不会回显。
4. 在知识库文档中划选英文词，点击「加入生词」并保存。单词、释义、例句、翻译与来源先保存在 LazyMind 数据库，后台再将单词推送到已启用的目标。
5. 配置页显示待同步、失败、成功数量及最近记录。历史生词不会在连接后自动批量发送，点击「同步已有生词 / 重试」才会加入任务。

## 欧路连接

在欧路官方[授权页面](https://my.eudic.net/OpenAPI/Authorization)登录后，复制完整的个人授权信息到配置页。保留授权值自带的前缀，不要另外添加 `Bearer`，也不需要粘贴 `Authorization:` 字段名。点击验证只读取词本，不会导入单词。

当前接入英语生词本。验证后可搜索并选择已有词本，只有一个词本时自动选中；没有词本时可手动创建。点击「保存并启用」完成连接。授权无效、请求限流、已保存凭据不可读取等错误会单独提示；网络失败时可直接重试读取词本。

欧路同步按官方请求额度节流。遇到限流会延迟任务，不会影响本地收藏；请勿连续重复点击验证或历史同步。新增词使用官方 `words` 参数，保留远端已有单词的星级。

## 范围与语义

- 第一版同步英文单词，不上传原文例句、笔记、释义、文档内容或附件；这些资料仍保存在本地。
- 墨墨默认仅加入云词本。「同时加入学习计划」需单独勾选。学习接口为官方公测，要求墨墨 App 开启自动同步，并受账号可用单词额度限制。新建词本使用未发布状态；选择已有词本会保留其原状态。
- 本地删除不会删除远端词；不拉取远端复习记录或进行双向覆盖。待发送时发现本地单词已删除，将取消任务。
- 重复收藏只补充本地来源，不重复推送到同一目标。修改目标词本或学习计划选项后，历史词需要手动补同步。
- 网络错误会后台重试，限流按冷却时间延后；达到重试上限后保留失败记录，可手动重试。过期 Token 需重新填写。
- 停用或断开连接取消未完成任务，不删除本地和远端内容。已发出的请求无法撤回。更换 Token 会建立新的连接身份，旧任务不会发送到新账号。
- Token 使用项目凭据库加密保存，不包含在响应、异步任务载荷或同步记录中。迁移数据库到另一设备时可能需要重新填写 Token。
- 同一远端账号的任务串行执行，墨墨追加时读取并保留现有内容。墨墨没有公开的条件更新接口，因此外部客户端同时编辑同一词本仍可能发生覆盖；建议使用独立的 LazyMind 词本。

## 运行与验证

Core 需要设置 `LAZYMIND_VOCABULARY_ENABLED=true` 才会注册生词及云同步接口；前端构建也需启用对应的 `VITE_VOCABULARY_ENABLED`。仓库 Compose 默认开启，但旧 `.env` 或旧容器可能仍为 `false`，修改后需重建相应服务；仅替换前端不能更新后端接口。

Linux Docker 部署需显式配置 `LAZYMIND_CREDENTIAL_KEY_DIR`，否则凭据库默认拒绝保存 Token。本地 8090 环境使用以下 Core override：

```yaml
services:
  core:
    environment:
      LAZYMIND_VOCABULARY_ENABLED: "true"
      LAZYMIND_CREDENTIAL_KEY_DIR: /var/lib/lazymind/credential-vault/keys
    volumes:
      - ./data/core/credential-vault:/var/lib/lazymind/credential-vault
```

让 Core 在持久化挂载目录中创建 `keys` 子目录；该目录必须由容器进程用户拥有，权限为 `0700`，密钥文件权限为 `0600`。密钥不会保存在数据库内，也不能放进镜像或仓库。备份与迁移部署时，应将此目录和数据库一起保全；丢失密钥会使已有加密 Token 无法解密。macOS/Windows 默认仍使用系统安全存储。

已有数据库的升级应先做备份，保留已应用迁移文件，只补齐缺失的增量迁移；不要用仓库的新聚合 SQL 覆盖旧运行目录。更新 Core 后检查 `/api/core/vocabulary/cloud/connections` 返回连接列表而非 404，再在产品中输入个人 Token 完成远端授权验证。

同步由 Core 的后台任务执行；关闭后台任务时本地收藏与队列仍保留，重新启动任务后继续。未配置外部服务时，知识库收藏仍能独立保存本地生词。现有 Anki 生词入口保持原有行为。

自动化测试使用模拟 HTTP 服务，覆盖认证、响应校验、限流、重复发送、追加保留、跨账号隔离、加密存储、断开与 Token 轮换、持久化任务及重试竞态。真实账号联调需要用户在产品配置页填写 Token；不要将 Token 提交到仓库。
