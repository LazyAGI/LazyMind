## 4. 这次仍发生的问题与波动

### 大纲目录参数纠错一次

11:25:41 首次调用把目录拼成重复的 `ppt-workflow/ppt-workflow/…`，工具校验拒绝，用时 0.006 秒。11:25:51 修正后成功，用时 0.008 秒。两次之间约 10 秒的模型纠错已包含在 28.696 秒大纲阶段中，没有从头重跑工作流。

该失败属于目录参数错误，不是新文字大纲的 JSON 校验失败。目录仍让模型抄写，存在继续减少无效纠错的空间。

### 素材这次比上次慢

注册三张素材图：上次 3.763 秒，这次 10.252 秒，多 6.489 秒。素材整个阶段多 15.375 秒。素材来源不同，不能将这种网络波动当成结构后移带来的退化。

### 生成阶段承担更多工作，但本次实测仍缩短

这次生成工具 209.946 秒，比上次少 26.828 秒；它现在还包含内部大纲转换。因此结果表明本次样本的生成等待下降，但缺少各内部模型请求的完整拆分和重复样本，无法精确归因到某一项代码调整。

### 验证范围

日志确认生成工具成功、工作流 completed。用户自行端测；本轮没有自动浏览器测试或导出测试。Vocab 按要求不处理，触发前的连接警告不计入表内整轮时间。
