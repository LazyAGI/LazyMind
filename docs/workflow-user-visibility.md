# 工作流产出的用户侧展示

在 `workflow.yaml` 的顶层 `slots` 中声明 `user_visible`：

```yaml
slots:
  - id: draft_document
    label: 正文
    type: file
    user_visible: true
  - id: generation_prompt
    label: 生成提示词
    type: text
    user_visible: false
```

- `true`：普通用户侧展示；`false`：只在开发者侧按原有布局查看。
- 未填写时保持旧版本行为，默认展示。仅接受 YAML 布尔值，不接受字符串 `"false"`。
- 参数属于展示配置，不改变产物保存、步骤输入输出、执行依赖、审批或导出工具输入。
- 工作流面板会过滤对应槽位，递归移除组合布局中的隐藏节点，并移除已无产出的页签。无页签的自动布局同样遵守声明。切换开发者模式后恢复原布局。
- 普通用户任务列表的阶段产出、最终产出及分页计数使用同一声明；已有 `exposed: false` 仍然生效，`user_visible: true` 不会覆盖它。
- 已固定版本的会话按该版本声明生成普通用户投影。发布/导入新工作流版本后，新会话使用新声明；本次代码修改不会更新运行中的服务或自动迁移已有会话。

## 内置工作流的取舍

| 工作流 | 用户侧保留 |
| --- | --- |
| PPT | 需求、素材摘要、科研分析、风格选择、大纲、幻灯片/PPTX、讲稿 |
| Writer | 大纲、完整正文 |
| 图片工作流 | 生成/增强图片、静态表情、GIF、视频 |
| 图片工作流 v2 | 普通生成图、局部编辑结果、角色确认图、最终静态表情和 GIF |
| 学术论文 | 研究简报、方法、书目与综合、大纲、全文、审稿意见、修订响应、最终完整性报告和交付文件 |
| 投标技术方案 | 技术要求、废标风险、知识库依据、大纲、全文、架构/效果图、交付文件和校验报告 |
| 产品方案 | 各阶段完整文档及交互视图、PRD 大纲、交互原型 |
| Superpowers brief 示例 | 实现代码和测试输出 |
| Superpowers reliability 示例 | 最终结果 |
| 测试工作流 | 测试正文、附件、验证报告、状态 |

内部路由、Writer 上下文、章节中间稿、生成提示词、重复元数据和机器检查摘要保留为开发者产出。需要调整展示时只修改对应槽位的 `user_visible`，前端不按工作流 ID 或产物名称写判断。
