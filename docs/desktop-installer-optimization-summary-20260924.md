# LazyMind 桌面安装包优化总结

汇报日期：2026 年 9 月 24 日

本轮优化围绕降低首次安装下载量、减少冗余文件和支持能力按需安装展开。历史 Windows 构建记录显示，安装包由 **546.08 MiB 降至 448.30 MiB，减少 97.78 MiB，约 17.9%**。RAG 后置安装及文档入库已获得当前端测反馈确认；本轮审查重点检查了对其他功能的影响。

## 主要完成内容

| 优化方向 | 已完成工作 | 业务价值 |
| --- | --- | --- |
| 依赖精简 | 清理可重建缓存、指定依赖的测试文件和未使用的 SDK 服务模块，保留运行所需代码、元数据和许可证 | 减少安装包中的冗余内容 |
| RAG 按需安装 | 将知识库专用依赖从基础包拆出，通过设置页安装；Windows 和 Mac ARM64 固定复用已发布组件，并校验版本、大小及 SHA-256 | 将部分下载量推迟到使用知识库时，减少首次安装负担 |
| 服务按需启动 | 未安装 RAG 时不启动相关解析、索引等服务，保留普通聊天基础服务 | 避免基础启动等待未安装的组件；启动耗时和内存收益仍需专项测量 |
| 示例资源后置 | 示例会话改为启动准备阶段下载并缓存，下载失败允许继续启动 | 降低主安装包体积，保留后续获取示例的能力 |
| 跨平台构建完善 | 清理 Windows 中无用的开发产物和文档，处理 Python 解释器别名重复及中文路径问题，补充 Intel Mac 构建入口 | 减少重复资源，完善多平台交付流程 |
| 依赖共享与字体后置 | 完成相同纯 Python 依赖的保守共享机制，默认关闭；PDF 字体支持下载、校验和本地缓存 | 提供进一步减小体积的手段；字体及许可证已发布至 Hugging Face |

## 已有量化结果

| 指标 | 已记录结果 | 统计口径 |
| --- | --- | --- |
| Windows 安装包 | 546.08 → 448.30 MiB，减少约 17.9% | 9 月 20 日历史构建结果，非当前 rebase 后的新包测量 |
| Python 冗余清理 | 1369.05 → 1040.38 MiB，减少 328.67 MiB | 展开文件体积，不能直接等同于安装包下载节省 |
| RAG 独立组件 | Windows 约 66.13 MiB；Mac ARM64 约 51.99 MiB | 用户启用知识库时另行下载 |
| PDF 中文字体 | 约 16.95 MiB | 原始字体大小，已验证公开下载、完整性和离线缓存 |

Windows 对照来自相同源码基线的两次不同仓库构建，依赖和构建环境未完全锁定，因此不作为严格 A/B 实验。优化主要减少首次安装下载量；用户启用全部能力后仍需下载相应组件，不能将上述差值表述为总流量等量下降。

## 质量验证与当前状态

分支已完成与最新上游主线的 rebase。代码审查覆盖依赖裁剪、服务启停、运行时重启、PDF 字体、示例会话及构建流程。桌面脚本 265 项、Python 72 项、前端 8 项测试通过，runtime-manager 与 systemdeps 测试及 Core 编译检查通过；部分平台或资源相关测试跳过。上述结果不替代完整安装包真机验收。

审查确认并修复了一项非 RAG 发布问题：原 PDF 字体地址返回 404。字体原文件及许可证现已发布至 Hugging Face，应用配置固定到已验证的资源提交。真实 HTTPS 下载、大小及 SHA-256 校验、后端返回与断网缓存复用均通过，下载后的字体生成中文 PDF 并可正确提取文字。旧安装包仍使用旧地址，需要更新字体 catalog 或后续安装新版本；本轮已重打 Mac ARM64 RAG 组件，尚未重打完整安装包。

用户反馈当前 RAG 后置安装后能够正常入库。其他 RAG 缺陷由其他分支处理，本总结不将其计入安装包优化成果，也不将其视为已在本分支修复。

## 本轮补充：模型 SDK 精简与 gRPC 后置

- LazyLLM 独立分支 `cst/install_opt` 将 Doubao 图片和视频生成迁移到 requests，保留前端经 LazyLLM supplier 调用的路径，覆盖动态模型地址、鉴权、任务轮询及错误处理。未调用付费真实模型 API。
- 桌面移除 OpenSearch 及火山 SDK；解除 OpenSearch 对 gRPC 的依赖后，将 gRPC 放入 RAG 按需包。后续清理已从应用 requirements 和 Mac/Windows lock 中直接删除火山 SDK，避免先安装再裁剪；OpenSearch 仍仅在桌面移除。
- 新 Mac ARM64 RAG ZIP 为 **62.67 MiB**，展开约 **217.25 MiB**；比旧组件 51.99 MiB 增大，因为更多依赖从基础包移入。基础导入、组件 SHA/manifest、RAG 导入、Milvus 写入/flush/重启/查询/删除均已通过真实原生验证。
- 用户已将新 ZIP 上传 HF，公开仓库返回的文件大小和 SHA-256 与本地一致。应用优先下载 ModelScope，同名文件缺失、下载过慢或校验失败时自动切换 HF。字体使用相同机制。
- 新版完整安装包尚未生成，不能把展开依赖体积直接当作安装包压缩收益。Windows 与 Intel 本轮未发布新的原生组件；既有完整业务验收范围不扩大。
- LazyMind 与 LazyLLM 分别提交，随后主仓已更新子模块指针到 `fb0da5aa`，Actions 分支构建可检出配套源码。

后续已接入同事的 Skill 后置 PR，并完成精选素材云端拆包，详见下节。

火山 SDK 已从安装输入中彻底排除，旧的按服务裁剪逻辑已删除。此项继续优化的是构建下载、安装和清理开销；上一版最终包已移除 SDK，不能再次宣称节省 185 MiB 或据此推算 DMG 节省。缓存和测试目录的通用裁剪保留。

## 精选资源后置与 PR #778 集成

已接入 PR #778 的 `402fe46db`：构建及启动只生成锁定 Skill 目录预览，用户显式安装/使用时才下载远端 Skill ZIP；保留原有完整性校验、补丁校验和已安装复用逻辑。

精选案例另按案例拆分资源：46 个独立 ZIP，合计 77,565,150 字节（73.97 MiB），发布到 HF `LazyAGI/LazyMind/featured-assets/`。构建仅保留 46 张 JPEG 封面缩略图，1,304,579 字节（1.24 MiB）；原编译素材为 172,009,247 字节（164.04 MiB），本轮移出/缩小约 162.79 MiB 展开文件，实际 DMG 下载收益以新 Actions 产物为准。

详情页面首次请求图片/HTML 时，Core 按固定资源清单下载对应案例 ZIP，ModelScope 不可用或过慢时切换同名 HF 文件；校验压缩包和每个文件后解压至用户 runtime 缓存。首页封面内置，立即展示；Chat 历史样例下载导入完成后，后台优先预取首页 Chat/Work 各前 8 个精选的完整素材，再补齐其余可见案例，界面不等待全量资源。同一案例并发请求合并，后续访问复用缓存，损坏资源重新获取；下载失败可刷新页面重试，不阻止普通聊天。云端/Local 原有静态资源路由保持不变。

验证包括：PR 相关 8 个 Core 包、Core 编译、runtime-manager、53 项桌面脚本测试、19 项前端定向测试，以及 46 包真实解压/逐文件校验、封面与编译目录一致性、HTTP 主备回退/缓存复用/损坏恢复/非法 ZIP 拒绝。没有宣称完成新 DMG 真机业务验收。

HF 数据集重建后已重新上传 46 个精选 ZIP（`featured-assets/`）、PDF 中文字体、OFL 许可证及 Mac ARM64 RAG 包。字体地址重新固定到新仓库提交 `211752ef6607f899e94f1b01e4c0bfb7285240ac`，避免引用已不存在的旧提交。
