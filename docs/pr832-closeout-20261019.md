## 修复与根因

- Google 刷新接口返回 `invalid_grant`，此前 HTTP 错误被转换成普通异常，连接进入 ERROR，调用方收到通用 502。现在保留供应商错误码，刷新授权失效进入 EXPIRED，首次失败及后续本人访问返回 HTTP 409 / `1000833` / `CLOUD_CONNECTION_REAUTH_REQUIRED`。
- HTTP 408、429、5xx 及网络/超时异常可重试；临时失败保留 ACTIVE，随后刷新可恢复。其他不可重试错误仍进入 ERROR，不把应用凭据错误当作授权过期。
- 归属校验在状态检查之前；并发刷新已保存有效 token 时，优先恢复该结果。重新授权沿用既有入口和原连接，拒绝错误账号及跨用户访问。未扩展既有刷新并发算法。
- Drive 工具文档测试的子进程实际工作已完成，但退出时 tracing flush 扫描现用的大型 trace 目录；聊天启动计时则受 macOS 挂载文件系统导入开销影响。两项测试现使用独立临时 trace 目录，并从容器内部源码执行。tracing 保持启用，3 秒启动阈值和 30 秒文档测试超时保持不变；runtime probe 原有 35 秒默认超时也未修改。
