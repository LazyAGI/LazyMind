# LazyMind v0.2

## 综述

LazyMind v0.2 让产品从一个以对话为中心的 AI 助手，进一步成为能够承接复杂工作、从理解意图一路走到成果交付的工作空间。

这一版本带来了端到端的 AI 写作工作区、可将 Skill 转化为可视化且可恢复工作流的插件运行时，以及经过大幅扩展的自进化系统，覆盖评测、版本管理、灰度发布与回滚。与此同时，原生桌面端、本地文档与数据库访问，以及更完整的图像生成工作流，也让 LazyMind 更适合成为日常使用的本地工作入口。

围绕这些基础能力，v0.2 还新增了记忆与偏好进化、分组定时任务、结构化回答、可复用 Prompt Library、更完整的 Skill 管理和更清晰的知识库问题诊断，并持续改进了对话、数据源、第三方集成和系统可靠性。

## Highlights

### AI 写作工作区

写作不再只是一次性的对话回答，而是一条完整的工作流。LazyMind 可以围绕一个主题或一份已有文档，完成上下文整理、大纲生成、章节规划、初稿撰写、审阅、修订和交付。写作工作区采用结构化文档模型，支持块级编辑、拖拽排序、草稿自动保存和检查点管理；在重试或继续工作流之前，还会先同步尚未保存的编辑。最终成果既可以导出为 Markdown 文件，也可以写回已绑定的飞书文档，并保留完整的修订历史。

### 从 Skill 到可视、可恢复的工作流

v0.2 为长任务引入了插件运行时和可视化状态图。现在，一个 Skill 可以转化为按步骤执行的工作流，输入材料、中间产物、关键判断和最终输出都可以被看到。你可以随时查看进度，在需要调整的步骤介入，或在不丢弃已有成果的情况下重试和回滚；整个执行过程中的产物也会保留版本。新的状态编辑器和 UI 编辑器，则为将自然语言描述的方法沉淀成稳定、可复用的流程打下了基础。

### 可评测、可灰度、可回滚的自进化

自进化系统围绕可追踪的产物和操作进行了重构。LazyMind 可以收集反馈与 bad case，判断问题来自数据、检索、Prompt、工具调用还是算法策略，并通过隔离测试和 A/B 评测验证候选算法。通过验证的算法版本可以完成注册，按知识库或流量分组逐步灰度，在效果达标后升级为主版本，也可以在需要时回滚。新的界面进一步展示了执行 Trace、评测报告、任务进度、中间结果，以及暂停和取消控制。

### 原生桌面端与本地优先运行时

LazyMind 现在可以作为原生桌面应用运行，日常本地使用不再依赖完整的 Docker 部署。新的宿主机运行时将核心服务移出容器，在本地使用 SQLite 和 Milvus Lite，支持原生文件扫描、动态端口、局域网访问来源，并按照不同操作系统的规范管理应用数据。v0.2 提供了 macOS 和 Windows 的桌面打包与安装流程，并改进了安全升级、运行时清理、启动预热和 CI 构建流水线。

### 从一个想法，到一张图片，再到一段动画

图像创作已经接入 LazyMind 的工具和工作流系统。图像插件可以调用工具收集或准备素材，根据任务复杂度选择直接生成或多步骤工作流，保存中间产物，并支持生成后的持续编辑。生成的图片还可以进一步转成 GIF 动画；新增的预检和渲染改进也让整条创作链路更加稳定。

## Other Features

- **记忆与偏好：** LazyMind 可以将反馈转化为对记忆、习惯、Skill 和用户偏好的待审核更新。版本历史、差异对比、审批状态、自动更新控制和回滚，让每一次变化都透明且可逆。相关 PR：[#158](https://github.com/LazyAGI/LazyMind/pull/158)、[#194](https://github.com/LazyAGI/LazyMind/pull/194)、[#195](https://github.com/LazyAGI/LazyMind/pull/195)、[#224](https://github.com/LazyAGI/LazyMind/pull/224)、[#297](https://github.com/LazyAGI/LazyMind/pull/297)、[#340](https://github.com/LazyAGI/LazyMind/pull/340)、[#345](https://github.com/LazyAGI/LazyMind/pull/345)

- **分组定时任务：** Task Center 可以关联日、周、月等不同周期的任务，让日常积累的结果自动成为后续汇总和趋势分析的输入，而不是停留在彼此孤立的单次运行中。相关 PR：[#397](https://github.com/LazyAGI/LazyMind/pull/397)

- **结构化对话：** LazyMind 可以在对话中直接以 Mermaid 图、表格、树、时间线、卡片和分栏等交互形式呈现复杂内容。相关 PR：[#306](https://github.com/LazyAGI/LazyMind/pull/306)

- **Ask User：** Agent 可以在继续执行前，通过结构化问题向用户补充关键信息。v0.2 支持编辑预设选项、自由填写、部分问题提交、历史答案恢复和提交后防重复操作，并提高了工具调用的稳定性。相关 PR：[#271](https://github.com/LazyAGI/LazyMind/pull/271)、[#403](https://github.com/LazyAGI/LazyMind/pull/403)

- **可复用 Prompt Library：** Prompt 可以按类别组织，支持搜索、筛选、卡片预览、收藏和复用；分类统计与使用次数也会正确匹配当前筛选条件和模型映射。相关 PR：[#345](https://github.com/LazyAGI/LazyMind/pull/345)、[#373](https://github.com/LazyAGI/LazyMind/pull/373)、[#381](https://github.com/LazyAGI/LazyMind/pull/381)、[#394](https://github.com/LazyAGI/LazyMind/pull/394)

- **Skill 管理：** v0.2 新增 Skill V2 资源模型、文件夹与文件浏览、Skill 包编辑、从公开 GitHub 仓库导入安装、广场分类与标签、版本管理、整理工作流和更完整的评审统计。相关 PR：[#308](https://github.com/LazyAGI/LazyMind/pull/308)、[#316](https://github.com/LazyAGI/LazyMind/pull/316)、[#325](https://github.com/LazyAGI/LazyMind/pull/325)、[#342](https://github.com/LazyAGI/LazyMind/pull/342)、[#351](https://github.com/LazyAGI/LazyMind/pull/351)、[#352](https://github.com/LazyAGI/LazyMind/pull/352)、[#382](https://github.com/LazyAGI/LazyMind/pull/382)、[#411](https://github.com/LazyAGI/LazyMind/pull/411)

- **本地文档与数据库问答：** 本地文件系统数据源现在具备明确的作用域和权限边界，支持重命名，并可按绑定决定是否参与对话。LazyMind 还可以只读访问自身数据和外部在线数据库，完成跨知识库、文档、数据源及关联关系的宏观问答。相关 PR：[#259](https://github.com/LazyAGI/LazyMind/pull/259)、[#277](https://github.com/LazyAGI/LazyMind/pull/277)、[#282](https://github.com/LazyAGI/LazyMind/pull/282)、[#363](https://github.com/LazyAGI/LazyMind/pull/363)
