# LazyMind v0.2

## Overview

LazyMind v0.2 turns the product from a chat-centered assistant into a workspace for carrying complex work from intent to delivery.

This release introduces an end-to-end AI writing workspace, a workflow runtime that can turn reusable Skills into visible and resumable workflows, and a substantially expanded self-evolution system with evaluation, versioning, staged rollout, and rollback. It also brings LazyMind closer to local, everyday use with native desktop packaging, local document and database access, and richer image-generation workflows.

Around those foundations, v0.2 adds memory and preference evolution, grouped scheduled tasks, structured answers, reusable prompts, broader Skill management, clearer knowledge-base diagnostics, and many smaller improvements across chat, data sources, integrations, and reliability.

## Highlights

### AI Writing Workspace

Writing is now a complete workflow rather than a one-off chat response. LazyMind can take a topic or source document through context gathering, outlining, section planning, drafting, review, revision, and delivery. The Writer workspace uses a structured document model, supports block-level editing and reordering, autosaves drafts, keeps checkpoints, and flushes pending edits before retrying or continuing a workflow. It can deliver Markdown files or update bound Feishu documents while preserving revision history.

### Skills become visible, resumable workflows

v0.2 introduces a workflow runtime and visual state graph for long-running work. A Skill can now become a step-by-step workflow whose inputs, intermediate artifacts, decisions, and outputs remain visible. You can inspect progress, intervene at the affected step, retry or roll back without discarding completed work, and keep versioned artifacts throughout the run. The new state and UI editors lay the groundwork for turning natural-language methods into stable, reusable processes.

### Self-evolution with evaluation, staged rollout, and rollback

The self-evolution system has been rebuilt around traceable artifacts and operations. LazyMind can collect feedback and bad cases, diagnose whether a failure came from data, retrieval, prompts, tools, or algorithm strategy, and validate a candidate algorithm through isolated tests and A/B evaluation. Algorithm versions can then be registered, rolled out gradually by knowledge base or traffic segment, promoted when validation succeeds, and rolled back when needed. The UI now exposes traces, evaluation reports, progress, pause/cancel controls, and clearer intermediate results.

### Native desktop and local-first runtime

LazyMind can now run as a native desktop application instead of requiring the full Docker deployment for everyday local use. The new host runtime moves core services out of containers, uses SQLite and Milvus Lite locally, supports native file scanning, handles dynamic ports and LAN origins, and follows platform conventions for application data. v0.2 includes desktop packaging and installers for macOS and Windows, including safer upgrades, runtime cleanup, warm-up, and CI build pipelines.

### From an idea to an image—and an animation

Image creation is now integrated with LazyMind's tool and workflow system. The image workflow can call tools to collect or prepare source material, choose between direct generation and a multi-step workflow, retain intermediate artifacts, and support follow-up editing. Generated images can also be turned into GIF animations, while preflight checks and rendering improvements make the workflow more dependable.

## Other Features

- **Memory and preferences:** LazyMind can turn feedback into reviewable updates to memories, habits, Skills, and user preferences. Version history, diffs, approval states, auto-update controls, and rollback make those changes transparent and reversible. Related PRs: [#158](https://github.com/LazyAGI/LazyMind/pull/158), [#194](https://github.com/LazyAGI/LazyMind/pull/194), [#195](https://github.com/LazyAGI/LazyMind/pull/195), [#224](https://github.com/LazyAGI/LazyMind/pull/224), [#297](https://github.com/LazyAGI/LazyMind/pull/297), [#340](https://github.com/LazyAGI/LazyMind/pull/340), [#345](https://github.com/LazyAGI/LazyMind/pull/345)

- **Grouped scheduled tasks:** Task Center can connect related daily, weekly, and monthly tasks, allowing accumulated results to feed later synthesis and trend analysis instead of remaining isolated runs. Related PR: [#397](https://github.com/LazyAGI/LazyMind/pull/397)

- **Structured Chat:** LazyMind can present complex answers as Mermaid diagrams, tables, trees, timelines, cards, columns, and other interactive structures directly in chat. Related PR: [#306](https://github.com/LazyAGI/LazyMind/pull/306)

- **Ask User:** Agents can ask structured clarification questions before continuing. v0.2 adds editable options, optional free-form answers, partial submission, restored answers in conversation history, safer repeat-submission behavior, and more reliable invocation. Related PRs: [#271](https://github.com/LazyAGI/LazyMind/pull/271), [#403](https://github.com/LazyAGI/LazyMind/pull/403)

- **Reusable Prompt Library:** Prompts can be organized by category, searched and filtered, previewed as cards, favorited, and reused. Facet counts and usage tracking now stay aligned with active filters and model mappings. - **Skill management:** v0.2 adds the Skill V2 resource model, folder and file browsing, package editing, import and installation from public GitHub repositories, plaza categories and tags, version management, organization workflows, and improved review statistics. Related PRs: [#308](https://github.com/LazyAGI/LazyMind/pull/308), [#316](https://github.com/LazyAGI/LazyMind/pull/316), [#325](https://github.com/LazyAGI/LazyMind/pull/325), [#342](https://github.com/LazyAGI/LazyMind/pull/342), [#351](https://github.com/LazyAGI/LazyMind/pull/351), [#352](https://github.com/LazyAGI/LazyMind/pull/352), [#382](https://github.com/LazyAGI/LazyMind/pull/382), [#411](https://github.com/LazyAGI/LazyMind/pull/411)

LazyMind can also answer read-only, macro-level questions across its own data and external online databases. Related PRs: [#259](https://github.com/LazyAGI/LazyMind/pull/259), [#277](https://github.com/LazyAGI/LazyMind/pull/277), [#282](https://github.com/LazyAGI/LazyMind/pull/282), [#363](https://github.com/LazyAGI/LazyMind/pull/363)
