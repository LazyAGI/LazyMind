# 默认模型工具配置收拢设计

## 目标

将搜索、学术检索、OCR 和机器翻译统一收进“默认模型”页面的“检索与工具”分组，通过各行的“去配置”按钮打开配置弹窗。页面不再在默认模型列表下方铺开完整的第三方服务配置区。

同时精简当前公开的机器翻译服务：删除 MyMemory；需要密钥的服务仅展示百度翻译、阿里云机器翻译和小牛翻译。其他需要密钥的翻译实现保留为休眠代码，以便以后重新接回。

## 信息架构

“检索与工具”固定按以下顺序显示：

1. 搜索引擎
2. 学术搜索引擎
3. 文档解析（OCR）
4. 机器翻译

每一行展示服务名称、简短说明、当前配置摘要和“去配置”按钮。点击按钮打开仅包含该类别的宽弹窗。关闭弹窗后仍停留在默认模型页面；保存或选择服务后，当前行的摘要立即刷新。

旧的知识与数据工具深链接继续重定向到默认模型页面，并自动打开对应类别的弹窗。

## 机器翻译服务范围

### 无需密钥

保留：

- Google Translate Web
- Bing Translate Web
- Sogou Translate Web
- DeepL Web
- Tencent TranSmart Web

以上五个免密钥服务默认全部启用，无需用户逐个配置。首次使用默认选择 Google Translate Web，后续保留用户主动选择的可用来源。

MyMemory 从模型目录、翻译注册表、调用分发、实现代码和对应测试中删除。

### 需要密钥

当前公开目录仅保留：

- Baidu Translation
- Aliyun Translation
- Niutrans

其他需要密钥的翻译提供方从公开目录和可选注册表移出，但保留其调用实现，不做物理删除。已有实现应保持可独立恢复；当前界面和新配置流程不能再展示或选择这些提供方。

## 组件边界

- `DefaultModelConfigPanel` 负责“检索与工具”的四行、固定排序、配置摘要和打开配置的动作。
- `DefaultServicesPage` 负责弹窗状态、深链接聚焦、保存后的数据刷新，不再渲染页面下方的常驻配置区。
- `ExternalServicesPage` 继续负责单个类别内部的服务列表、凭据教程、保存和选择逻辑，通过现有类别过滤能力嵌入弹窗。
- 翻译服务目录是公开可配置服务的来源；翻译运行时注册表只包含当前公开来源和仍需运行的无密钥来源。

## 交互与视觉

沿用默认模型页面现有行式布局、间距、字体和状态表达，不另造卡片系统。弹窗使用足够宽度容纳服务列表与配置教程，小屏下占满可用宽度并允许内容区滚动。

按钮、弹窗标题和关闭行为支持键盘操作；弹窗打开后聚焦标题或首个可操作控件，关闭后焦点返回原“去配置”按钮。遵循 `prefers-reduced-motion`，不增加非必要动画。

## 错误处理

- 配置列表加载失败时在弹窗内显示重试入口，不影响默认模型其他分组。
- 保存失败时保留用户输入并沿用现有错误提示。
- 某类别没有可用服务时仍展示该行，并在弹窗中给出明确空状态。
- 旧配置若指向已下线或删除的提供方，保留连接数据供恢复，当前默认改用已启用的 Google Translate Web，避免划词翻译继续调用已下线来源。

## 测试

- 前端组件测试验证四行的固定排序、常驻配置区消失以及四类弹窗按按钮打开。
- 路由测试验证旧工具链接重定向后自动打开正确弹窗。
- 翻译配置测试验证 MyMemory 完全消失、需密钥列表仅含百度/阿里云/小牛、无密钥列表保留五项。
- 后端测试验证 MyMemory 不再可分发，休眠的需密钥提供方不再公开注册。
- 运行相关前端单测、后端翻译包单测和构建检查。
