# 资料库后台任务统一入口

- 新增只读、权限隔离的文档处理任务分页接口；每份文档仅显示最近一次有效处理任务。批量读取精确任务绑定的后台状态，包含无 RAG 的原生解析。
- 解析、切片、向量索引分别展示证据；未请求的阶段不算排队，无阶段进度不伪造百分比。旧任务不能覆盖新任务；删除源不计未完成。
- 后台任务改为文档处理 / 安装与更新两个页签，保留官方任务功能。文档页提供状态、类型、关键词筛选，展开阶段和失败原因，跳转资料库处理或索引管理。
- 查询失败保留数据但明确标注过期，不误报完成；轮询避免重入与过期响应。
- 测试覆盖权限、最新任务、错误与取消、阶段语义、筛选分页、无组件原生解析；前端测试空态、错误、筛选、阶段展示及原安装功能。
- 编译部署原 Docker 项目，核对数据库绑定与记录数，浏览器验证新入口、阶段展开和小屏幕。
