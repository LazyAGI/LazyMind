# Source and authorization record

This built-in Workflow is a modified adaptation of an internal bid technical-proposal writing
Skill contributed by a company colleague.

- The contributor authorized the adaptation and its contribution to LazyMind.
- The contributor requested not to be identified publicly; no personal name or private source
  location is recorded here.
- The Workflow preserves the source Skill's business process while replacing environment-specific
  paths and execution assumptions with LazyMind Workflow state, typed materials, Writer integration,
  knowledge retrieval, human checkpoints, and Workflow-local scripts.
- Runtime code does not read or execute the original internal Skill directory.

This is an internal contribution record, not a claim that the source Skill was publicly released
or licensed by a third-party open-source project.
