# data_analysis: shared business method

Use complete bound data with original units, observation scopes and measurement conditions. Author a scientific analysis plan and code, execute through paper_analyze, then interpret actual results. Missing comparisons remain unavailable; do not manufacture matches or results. Choose figures after computation and render through paper_plot. Preserve signed numerical findings, input digests and source identities; add only supported interpretation. For redraw, freeze analysis and unchanged charts and update linked manuscript references. Output structured analysis and charts matching the returned schema.

Read plotting inputs exactly: statistics.results contains flattened executed rows with coordinates, label, metric, scope and value. Final statistics.findings stores coordinates inside calculation JSON, not as top-level coordinates. Use real row keys and fail clearly for missing series; never replace absent matches with zero. After rendering, inspect every actual PNG using host vision (native: vision_extractor from the multimodal tool; external: host image viewer). Compare visible values and sample counts with executed rows. A zero/empty plot is not accepted merely because rendering succeeded. Repair within budget before submitting; disclose unavailable vision instead of claiming it ran.
