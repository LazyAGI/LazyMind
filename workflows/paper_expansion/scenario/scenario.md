# 论文自动拓展
一个 Chat 对应一条个人记录，同 Chat 继续拓展追加轮次。快速和标准的独立拓展在检索筛选后交付论文清单；深入研究在清单之后分析论文并生成研究报告；综述在分析阶段继续准备文献。

快速扩展直接使用用户输入和种子定位核心问题；标准、深入及综述复用初调和确认方向。不在正式 Workflow 中再次选择方向或调用 ask_user。

快速交付有序相关论文清单。标准与深入共用两个步骤。检索与拓展保存逐方向的候选；筛选与补充读取候选、补查薄弱方向，再交付带理由的分组清单。深入以这份冻结清单为分析输入，补查证据但不增删或重新分组；综述仍可在分析中补充候选。服务端保存检索回执，用户种子始终保留，不以篇数为目标。

同一范围继续拓展沿用记录和 Chat，每轮保存完整结果；可调整非种子论文，用户种子与重点标记由服务端保留。实质改变方向回到记录补充调研并确认，仅调整表达重做最后一步。

候选必须来自本任务 academic_search_papers 的实际返回；禁止模型记忆补充候选。academic_read_paper 必须传 expansion_id。搜索失败或无结果如实展示，全文缺失时说明仅依据摘要；关系分析不得编造全文证据。保留全部用户种子，临时阅读不自动入库。轮次与工具调用上限用于终止无效循环，达到上限时保留有效成果并说明缺口。综述由另一个 Chat 执行。

检索与取文复用真实来源与服务，区分下载、正文身份、解析质量与实际阅读；普通拓展按需读取，综述目标为最终集合补取正文。关键结论附真实已读来源位置，区分原文陈述和研究推断，不能把预览或补充材料冒充论文全文。临时材料仅用于分析，只有用户确认导入才进入论文库。

快速清单按优先级排列，标准清单按确认方向组织。报告只使用有原文依据的关系和条件比较。轮次与工具调用达到上限时停止补查，交付可用结果。满足正文门槛后，综述在另一个 Chat 中接收冻结材料。
