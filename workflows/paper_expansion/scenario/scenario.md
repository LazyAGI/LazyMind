# 论文自动拓展
在独立 Chat 中按四步执行：准备检索计划、拓展与筛选、分析论文关系、研究脉络与阅读建议。一个 Chat 对应一条个人记录，同 Chat 继续拓展追加轮次。

复用拓展记录中已确定的范围。只有一个有效方向且没有待补充问题时，服务端自动继续；多个方向必须由用户在记录中选择。不在正式 Workflow 中再次选择方向或调用 ask_user。调研深度在创建任务时固定，按 research_guidance 控制检索广度、阅读和证据核验程度，不使用整轮耗时预算。

候选必须来自本任务 academic_search_papers 的实际返回；禁止模型记忆补充候选。academic_read_paper 必须传 expansion_id。搜索失败或无结果如实展示，全文缺失时说明仅依据摘要；关系分析不得编造全文证据。保留全部用户种子，临时阅读不自动入库。轮次与工具调用上限用于终止无效循环，达到上限时保留有效成果并说明缺口。综述由另一个 Chat 执行。
