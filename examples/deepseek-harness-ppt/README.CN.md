# 在 DeepSeek Harness 里，把一个想法做成可交付的 PPT

[English](README.md) · [全部案例](../README.CN.md)

> 从确认需求到审阅页面，让你在制作过程中决定这份 PPT 应该长什么样。

做一份介绍故宫的 PPT，需要决定讲哪些故事、用什么图片、每页放多少内容，以及怎样保持整套风格一致。等到全部生成完再发现方向不对，修改就容易变成另一轮制作。

这条演示把这些决定放进了同一个过程：用户在 DeepSeek Harness 中提出需求，LazyMind 展开工作流，逐步展示底图、内容和页面，用户审阅后再继续。

**[观看演示：DeepSeek Harness × LazyMind](https://www.bilibili.com/video/BV1Xcpt6REjc/)** · 1 分 29 秒 · 发布于 2026-10-09

## 一份故宫 PPT 是怎样做出来的

1. **先明确要做什么。** 连接 LazyMind 后，说明主题和风格，通过追问确认页数等要求。
2. **先看视觉方向。** 演示中可以预览故宫主题底图，在进入后续制作前判断风格是否合适。
3. **逐页检查要讲的内容。** 在工作流面板审阅大纲和每页内容，调整后再继续生成。
4. **查看能带走的成果。** 视频展示了包含建筑、文物照片的成品，以及导出后打开的 PDF。

## 值得留意的三个画面

- **约 00:36：接入入口。** 从 LazyMind 的外部 Agent 设置连接 DeepSeek Harness。
- **约 00:58：底图预览。** 在成稿前就能看到视觉方向。
- **约 01:17：导出结果。** 查看成品文件中的版式和内容。

这条案例适合需要做主题介绍、方案说明或分享汇报，又希望保留内容与视觉决策权的人。你可以沿用熟悉的 Harness 对话入口，把审阅放到资料和页面逐步成形的过程中。

## 开始体验

先按[快速开始](../../docs/quick_start.CN.md)运行 LazyMind，再参考 [DeepSeek Harness 接入说明](../../integrations/dsh-workflow/README.md)连接。准备一个主题，并说明受众、页数和视觉风格；可以从一份短演示开始。
