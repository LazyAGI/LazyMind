# DeepSeek Harness × LazyMind: from a request to a slide deck

[中文](README.CN.md) · [Examples](../README.md)

Start a presentation task in DeepSeek Harness and use LazyMind Workflow to clarify requirements, review intermediate content, and inspect the result. The video uses a presentation about Beijing's Palace Museum.

## What the video shows

- Connect LazyMind and clarify requirements such as slide count.
- Preview backgrounds and review the outline and slide content before generation.
- Inspect the deck and export options; the video shows an exported PDF.
