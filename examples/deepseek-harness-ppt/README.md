# Turn an idea into a presentation inside DeepSeek Harness

[中文](README.CN.md) · [All examples](../README.md)

> Make decisions about your deck while it is taking shape—from requirements to slide review.

A presentation about the Palace Museum needs a story, suitable images, a clear structure, and a consistent visual style. Discovering that the direction is wrong after every slide has been generated can mean another round of work.

This demo brings those decisions into one process. The user starts in DeepSeek Harness; LazyMind opens a workflow with backgrounds, content, and slides that can be reviewed before continuing.

**[Watch DeepSeek Harness × LazyMind](https://www.bilibili.com/video/BV1Xcpt6REjc/)** · 1:29 · Chinese · Published 2026-10-09

## Follow the deck from request to result

1. **Clarify the brief.** Connect LazyMind, describe the topic and style, and answer questions about requirements such as slide count.
2. **Check the visual direction.** Preview the Palace Museum backgrounds before moving on to the finished deck.
3. **Review the content page by page.** Inspect the outline and per-slide content in the workflow panel, then continue with the revisions.
4. **Inspect the deliverable.** The video shows slides with architecture and artifact photographs, followed by an exported PDF.

## Three moments to watch

- **Around 0:36: connection setup.** Connect Harness through LazyMind's external-agent settings.
- **Around 0:58: background preview.** See the visual direction before the final slides.
- **Around 1:17: exported result.** Inspect the layout and content in the output file.

This is a useful starting point for topic introductions, proposals, and presentations where you want to keep control of both content and visuals. Start from the Harness conversation you already use, and review the work as it develops.

## Try it

Run LazyMind using the [quick start](../../docs/quick_start.md), then follow the [DeepSeek Harness integration guide](../../integrations/dsh-workflow/README.md). Choose a topic and describe the audience, slide count, and visual style. A short deck is a good first task.
