# 把 AI Agent 请进你的工作流

[English](README.md) · [全部案例](../README.CN.md)

> 让资料、工具和成果在同一个任务中衔接起来。

一个实际任务往往横跨好几个环节：查资料、整理观点、写文档、做演示，再把结果交给别人。工具越来越多，人在它们之间复制内容、解释上下文、检查输出的工作也可能越来越多。

这条产品介绍围绕 LazyMind 的定位展开：连接不同的 Agent 与工具，让它们围绕一个复杂任务协同工作。适合第一次接触 LazyMind、想先理解它能放在工作流程哪个位置的读者。

## 从自己的工作出发理解它

可以选一个你经常做的任务，想一想其中三个环节：

1. **输入在哪里？** 任务需要哪些资料、要求和背景？
2. **中间怎样衔接？** 上一步整理的内容，如何进入下一步写作、分析或制作？
3. **结果在哪里确认？** 哪些判断需要你审阅，哪些成果需要继续编辑和交付？

这些问题帮助你判断工作流的价值：把重复的衔接工作组织起来，让人能在需要判断的地方参与。
