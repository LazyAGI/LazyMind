# Codex × LazyMind：制作并迭代 PPT

[English](README.md) · [案例首页](../README.CN.md)

在 Codex 中提出北京故宫主题 PPT 需求，调用 LazyMind Workflow，通过面板审阅中间内容，并调整生成后的幻灯片元素。

## 演示内容

- 接入 LazyMind，并在任务中说明主题、风格和审阅要求。
- 查看和修改大纲、逐页内容。
- 选中成稿中的单个元素进行调整。
