# 在 Codex 里做 PPT，生成过程中就能参与修改

[English](README.md) · [全部案例](../README.CN.md)

> 大纲可以提前改，成稿中的单个元素也能选中调整。

做 PPT 时，你可能很清楚哪些地方必须自己把关：故事顺序是否合理、重点有没有突出、某一段文字是不是太长。把这些判断留到最终文件生成后，往往意味着重新解释需求。

这条故宫主题演示展示了另一种参与方式：在 Codex 中发起任务，用 LazyMind 面板查看中间内容，并把修改落到具体页面和元素上。

**[观看演示：Codex × LazyMind](https://www.bilibili.com/video/BV1TppR6xEj7/)** · 1 分 23 秒 · 发布于 2026-10-12

## 从一句需求到一次具体修改

- **把要求写进任务。** 主题、风格和希望停下来审阅的位置，都可以在开始时说明。
- **在生成前检查内容。** 通过面板查看大纲和逐页内容，先调整要讲什么，再推进制作。
- **对着成稿指出修改位置。** 视频后段展示了选中幻灯片中的元素，让修改对象更明确。
- **回到整页检查效果。** 看修改后的页面是否仍然符合整套演示的表达与风格。

## 看视频时，重点看这两段

**约 00:52 的逐页内容审阅**，展示了如何在成稿前参与内容组织。**约 01:00 的元素选择**，展示了如何把“这里需要改”落实到页面里的具体位置。

这条案例的重点是制作过程的可控性。它适合已经使用 Codex，又希望在 PPT 制作中保留审阅和修改入口的人；最终的故宫页面则提供了一个直观的结果参考。

## 开始体验

运行 LazyMind 后，按 [Codex 接入说明](../../integrations/codex-workflow/README.md)完成连接。选择一个熟悉的主题，说明内容与风格要求，并明确要求在大纲或逐页内容阶段停下来审阅。

首次使用可从[快速开始](../../docs/quick_start.CN.md)进入。
