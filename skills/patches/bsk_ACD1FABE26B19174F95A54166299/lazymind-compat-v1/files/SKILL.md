# 全网招中标情报助手

## 当前可执行范围

通过包内 scripts/bid_client.sh 执行官方 POST JSON 查询：search（SearchProjectForAI）、detail（getZTBProjectDetail）、source（getCollectUrl）。优先完成商机检索和重点项目分析。合同深度分析、拟在建专用搜索、企业全景画像与自动预警尚未接入，不能声称已执行这些功能。

需要系统 Python 3 和用户授权的 BBIAO_API_KEY。支持运行环境变量或用户指定的本地 JSON 凭证文件（字段 BBIAO_API_KEY）；不把凭证写入脚本、报告或完整请求URL，不自动永久保存。缺失时请用户配置。

## 执行流程

1. 明确关键词、地区、时间和公告阶段。默认近30天、全国；商机默认招标信息。用户要中标动态则选择中标信息。用户仅说“长三角”时分上海、江苏、浙江、安徽分别查询，不假定API支持复合区域名。
2. 使用 run_script，name 取实际加载名称，rel_path=scripts/bid_client.sh，args 为字符串数组，不设置外部 cwd，不新建辅助Skill、不创建临时探针、不用网页GET代替POST接口。
3. 先取每地区一页，每页5条。检查 selection 中实际过滤条件、api_total、unique_notice_count、has_next；返回数量不等于全部命中数量。没有相关结果时说明原条件，经说明后最多扩大一次同义词或日期，不静默改变范围。用户要求全量时分页获取，不能仅凭第一页做全量排名；注意额度。
4. 跨页/跨地区按 id+publishTime 去重公告。同一采购的意向、变更、招标、中标可能有不同ID，需核对项目编号/名称和采购方合并，不直接累加为独立商机。
5. 挑选最相关的1–2个项目，用返回的 id 和 publishTime 获取 detail 与 source，核对摘要、正文、阶段、地区和金额。检索关键词命中不代表符合目标行业，排除正文不相关项目并说明原因。
6. 保存一份 Markdown 报告：查询口径及覆盖范围 → 去重项目清单 → 重点机会及证据 → 下一步。列表包含名称、采购方、公告阶段、地区、金额及金额类型、日期、原文链接。缺失值写“未披露”，不要补造。

## 参数示例

`["search","--keyword","机器视觉","--area","江苏","--stage","招标信息","--start","2026-08-16","--end","2026-09-15","--page","1","--page-size","5"]`

日期按任务调整；--area 为空代表全国；--company 可筛企业；--exclude 为排除词。多关键词AND用空格，OR用竖线。默认检索按发布时间降序。

`["detail","--id","检索返回的ID","--published","检索返回的publishTime"]`

将 detail 换成 source 获取原文地址。若用本地凭证文件，在参数开头加 `["--credential-file","用户指定的绝对路径"]`，让脚本直接读取，不先列出或回显凭证。

## 证据与停止规则

- 必须检查输出 ok，HTTP200不代表业务成功。认证失败或0100590006额度不足立即停止，不循环重试；网络失败最多重试一次；空列表是有效查询结果。
- 预算、中标金额、单价和合同总额分别标注，不能混加；没有金额不记为0。
- 公告截止不自动等同于投标截止；历史公告不宣称当前可投。空采购方/代理字段仅表示未披露。
- “无特定资格要求”不等于没有通用资格门槛；“接受联合体”不等于允许只投某模块、分包或拆标。采购方名称按原文保留，疑似错字标注待核实，不自行改成另一名称。来源页面未打开时只能说已取得来源URL，不能说已核对来源全文。
- 样本不得推导全行业市场份额、完整排名或价格趋势；建议与公告事实分开，不承诺中标。
- 不调用未列入当前客户端的接口，不注册、购买、投标、订阅或联系采购方。
