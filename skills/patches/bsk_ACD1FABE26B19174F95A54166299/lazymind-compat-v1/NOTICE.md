# 来源与本地适配

原 Skill：https://skillhub.cn/skills/org-mbvufw6y/whole-network-bid-intelligence-assistant

本地适配提供固定 POST API 客户端、检索字段映射、业务错误识别和凭证脱敏；增加 LazyMind 精选能力配置、任务回放与真实检索结果展示。来源说明保留在产品描述和本文件中。

示例基于 2026-09-15 的实测报告：四地分别检索、取得13条公告、按采购项目归并为10项，并核对其中两项的接口详情正文及来源地址。来源网页未打开，江苏和浙江仅查询首页；示例不是全量商机统计，也不保证当前仍可投标。第三方服务需要用户自己的授权与额度。

## 认证方式验证（2026-09-15）

客户端使用 HTTPS POST JSON Body 中的 `key` 字段，不再把密钥写入 URL 或请求头。搜索、详情、附件列表、来源地址四种接口均返回业务码 200；搜索与详情有实际数据，空附件/来源仍按真实响应处理。Header key 和 Bearer 的验证返回 403。此处仅记录接口实测支持，不代表供应商正式协议承诺。

仍禁止输出请求 Body 或凭据；禁止跟随重定向，错误仅返回安全摘要，响应中的密钥会被替换。Body 认证消除了 URL 携密风险，但无法保证外部服务不记录请求体，部署方仍需关闭敏感请求体日志。
