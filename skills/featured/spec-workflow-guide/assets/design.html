可靠性决策

鉴权HMAC 覆盖时间戳与正文；事件 ID 同时作为幂等键。
顺序不同订单并行，同一 order_id 只允许一个在途事件。
重试非 2xx 指数退避，最多 5 次；超限进入 Dead。
恢复内部 API 按权限人工重放，保留操作者、原因和原结果。
追溯完整：首次投递 ≤30 秒、每分钟 500 个事件、5 次重试、同订单有序、签名与重放审计均映射到批准需求；没有新增 UI 或重做数据模型。
