ONE-PAGE GAME PITCH

《末班疑云》

在站厅彻底封锁前，用12分钟拼出失踪列车的真相；每拿一条线索，就少一条安全撤离路线。

三个相互作用的机制

封锁时钟 每3分钟关闭一个通道，改变最优路线。
巡逻声场 跑动更快但产生噪声，吸引机器人调查。
证据负重 携带实物线索降低速度；拍照更轻但信息不完整。
两周 MVP：1张站厅地图、3个巡逻机器人、6条线索、2种结局；验证玩家是否会因为新证据主动改路线。
