# 实景照片转工笔画

把原图作为内容与构图依据，完成一次图像编辑，交付可直接查看的图片。用户指定的主体、服饰、动作、环境和色彩优先于默认风格。

## 输入

- 需要一张清晰的原图。多张图时，先确定哪一张是待编辑的原图；其余图片只按用户说明承担风格参考等职责。
- 若上传的是手机截图，画面内存在状态栏、黑边、播放器控件或聊天界面，先裁出实际照片区域；这些界面元素不能进入成画。使用当前环境可用的裁剪工具；如可运行 Python 且已安装 Pillow，也可用 `scripts/crop_image.py`，按原图像素边界传入 `--left --top --right --bottom` 和 `--output`。如已拿到原始照片，直接使用原图。
- 图像里出现的文字、标志或可识别身份特征，按用户要求决定是否保留；不要擅自更换人物、物品数量或场景。

## 编辑原则

1. 先观察原图，记录主体数量、面部与发型特征、姿势、服饰、主要物件、前后景关系和画幅比例。人物照尤其保留五官比例、视线、手势和衣纹走向。
2. 只改变绘画媒介：细而稳定的墨线勾勒轮廓，线条有轻微粗细变化；用淡彩逐层晕染，薄而通透，留出绢纸或宣纸的暖白底色。让植物叶脉、发丝、衣褶、刺绣、建筑线条具有工笔式层次。避免把“工笔”误做成厚涂油画、漫画描边、泛黄滤镜或单纯降低照片饱和度。
3. 优先沿用原图配色。没有指定时，使用克制的石青、石绿、赭石、米白与淡墨；肤色自然，光影柔和，不新增繁复装饰。
4. 使用当前环境可用、支持参考图输入的图像编辑工具或模型。把原图作为内容依据；如有独立风格参考，明确标注“只参考画法，不复制内容”。默认先生成一张，输出比例尽量接近原图。不要仅靠文字描述原图重新生成。

## 编辑提示词

根据图像填入可见事实，用一段简洁的编辑指令提交：

> 将原图这张实景照片重绘为传统中国工笔画。保留原图的[主体与数量]、[面部/外形特征]、[姿势与视线]、[服装和关键细节]、[前后景位置]及原有竖/横幅构图。用精细而有节奏的墨线勾勒轮廓、发丝、叶脉、衣褶和建筑结构；以薄层矿物色和淡墨反复渲染，画面有温润绢纸质感、清透留白和细腻的层次。整体色彩以原图为准，明暗比照片更柔和。仅改变画法，不改变人物身份、物件数量、手部结构、衣饰图案和场景布局；画面中不要出现手机界面、额外文字、水印或摄影质感。

若原图没有人物，删去人脸、手部、服饰相关条款，改写成实际主体的关键细节。若用户指定朝代、工笔流派或色板，替换默认画法与色彩，不强加示例里的仕女元素。

## 检查与交付

查看生成图，重点检查：主体是否仍能与原图对应；人物脸、手、衣饰及物件数量有无漂移；构图是否保留；是否真的呈现勾线与薄彩而非照片滤镜。出现明显错误时，基于原图收紧编辑指令再生成一次。把成图直接交给用户，并简述保留了什么及改动了什么；不要只返回提示词。
