# 故事规划与爽文节奏

## 八维创意扩展

将一句话灵感扩展为可执行方案：

1. **题材定位**：主类型、混合类型、目标读者和差异化卖点。
2. **世界结构**：时代、空间、社会秩序、资源分配和主要矛盾。
3. **主角设计**：初始处境、欲望、缺陷、底线、核心能力和成长方向。
4. **核心冲突**：主角想要什么、谁在阻止、失败代价和冲突升级方式。
5. **回报机制**：能力成长、身份跃迁、关系改变、真相揭露和资源获得。
6. **力量或职业体系**：层级、门槛、成本、克制关系和可验证表现。
7. **配角与势力**：盟友、对手、镜像人物、中立势力及各自利益。
8. **开篇钩子**：异常事件、迫近期限、不可逆选择或认知反转。

用户没有指定时可以提供少量明确默认值，但不要一次堆叠过多流行元素。

## 一页式创作方案

默认包含：

- 暂定书名与一句话梗概
- 题材、基调与目标篇幅
- 主角起点、核心欲望和成长弧
- 金手指或核心机制及其限制
- 主要对手、核心冲突和失败代价
- 世界与力量体系摘要
- 前三章钩子和首个阶段性回报
- 差异化卖点与主要风险
- 需要用户确认的少量关键选择

方向足够明确且用户要求立即开写时，方案不是阻塞点：保存方案后继续建立大纲和第一章。

## 全局大纲

按“全书 → 卷 → 章节区间”逐层规划：

```markdown
# 全局大纲

## 全书主线
- 起点：
- 中点不可逆变化：
- 终局目标：
- 主角最终变化：

## 第 N 卷：<卷名>
- 卷目标：
- 核心矛盾：
- 新增规则/人物/地点：
- 主要升级与代价：
- 关键转折：
- 卷末高潮：
- 回收伏笔：
- 新埋伏笔：

### 章节区间
- 第 1—3 章：<建立处境与首个回报>
- 第 4—8 章：<冲突扩张>
- 第 9—12 章：<阶段高潮与代价>
```

大纲是方向约束，不是逐章僵硬剧本。发生合理的新发展时更新大纲并记录原因，不要让正文与过期大纲长期分离。

## 节奏参考

将节奏视为可调节的默认值：

- 每章至少产生一次有效变化：信息、关系、资源、能力、风险或选择。
- 每 1—2 章提供小回报或小反转。
- 每 3—5 章完成一次阶段冲突或明显升级。
- 每 8—12 章形成较大高潮、真相揭露或局势重组。
- 每 15—25 章完成一个卷级目标并引出新问题。

不要机械执行“被轻视—展示实力—围观震惊”。交替使用胜利、代价、误判修正、关系推进、秘密揭示和艰难选择，维持新鲜感。

## 力量与系统设计

任何金手指或体系都回答：

- 能做什么，不能做什么？
- 使用需要什么条件或代价？
- 如何衡量成长，而不是只报等级名？
- 什么力量可以克制它？
- 信息向谁公开，谁仍不知道？
- 新能力在使用前是否已有铺垫？

新增层级或规则时，立即同步到 `STORY_BIBLE.md`。
