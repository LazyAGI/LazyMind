# 小红书爆款种草文案生成器

## Overview

一键生成高点击率、高收藏率的小红书种草笔记。基于 10 套爆款标题公式和六段式正文结构，自动产出 3 个不同风格的完整笔记版本，每版包含备选标题、带 emoji 排版的正文、话题标签和发布建议。

适用于美妆、护肤、穿搭、美食、家居、数码、母婴等全品类种草场景。

## When to Use

- 用户要求撰写小红书种草笔记/推荐文/测评文
- 用户要求生成小红书爆款文案/标题
- 用户提供了产品信息，需要种草推广文案
- 用户提到"小红书文案""种草笔记""笔记生成"等关键词

## Input Requirements

用户需提供以下信息（缺失项主动询问）：

| 输入项 | 是否必填 | 说明 |
|--------|---------|------|
| 产品名称 | ✅ 必填 | 品牌+产品全称 |
| 产品卖点 | ✅ 必填 | 2-3 个核心卖点 |
| 目标人群 | ✅ 必填 | 如：油皮/学生党/宝妈/租房族 |
| 使用场景 | ✅ 必填 | 如：早八通勤/军训/追剧/换季 |
| 笔记风格 | ⬜ 可选 | 闺蜜分享/专业测评/故事叙事；不指定则输出3种风格 |

## Workflow

### Step 1: 解析输入信息

解析用户提供的产品信息，确认以下要素：
- 产品品类（美妆/穿搭/美食/家居/数码/母婴/其他）
- 核心卖点提炼为 2-3 个关键词
- 目标人群画像（年龄/身份/痛点）
- 使用场景描述
- 如有缺失必填项，向用户询问后再继续

### Step 2: 匹配爆款标题公式

加载 `references/title-formulas.md`，根据以下步骤生成标题：

1. 查阅"标题匹配决策表"，根据产品品类找到推荐公式排序
2. 结合目标人群和使用场景，从中选择 2-3 个最匹配的公式
3. 每个公式生成 1 条备选标题
4. 用"标题质量检查清单"逐条校验
5. 最终输出 3 条备选标题

### Step 3: 撰写六段式正文

加载 `references/copywriting-structure.md`，按以下结构撰写正文：

```
钩子开头 → 痛点共鸣 → 产品介绍 → 使用体验 → 效果展示 → 行动引导
```

每段严格遵循参考文件中的字数范围和写作技巧。

### Step 4: Emoji 排版

加载 `references/emoji-and-tags.md` 中的 emoji 使用规范：
- 根据产品品类选择对应的 emoji 推荐库
- 每段不超过 3 个 emoji
- 标题末尾可加 1 个 emoji
- 保持疏密得当，不堆砌

### Step 5: 话题标签推荐

加载 `references/emoji-and-tags.md` 中的标签推荐策略：
- 从大流量词库中选取 2-3 个品类相关标签
- 从中流量词库中选取 3-4 个精准标签
- 按长尾词生成规则动态生成 3-5 个长尾标签
- 合计 8-12 个标签，按相关性排序

### Step 6: 生成发布建议

加载 `references/publishing-strategy.md`，输出：
- 最佳发布时间（按时段+工作日/周末）
- 图片建议（首图类型+数量）
- 品类相关注意事项
- 互动引导话术

### Step 7: 输出 3 个版本

按"风格变体说明"生成 3 个差异化版本：

| 版本 | 风格 | 特点 |
|------|------|------|
| 版本A | 闺蜜分享型 | 热情口语化，emoji 密度高 |
| 版本B | 专业测评型 | 理性客观，有数据感 |
| 版本C | 故事叙事型 | 走心有情节，情绪起伏 |

如用户指定了特定风格，则主版本用指定风格，另外 2 版用其他风格补充。

## Output Format

每个版本按以下格式输出：

```
═══════════════════════════════════════
  版本X ｜ [风格名称]
═══════════════════════════════════════

📌 备选标题（3个）：
1. [标题1]
2. [标题2]
3. [标题3]

📝 正文：

[六段式正文，带 emoji 排版]

🏷️ 话题标签：
[8-12个标签，空格分隔]

📋 发布建议：
- 推荐发布时间：[时段]
- 推荐发布日期：[工作日/周末]
- 图片建议：[首图+数量]
- 互动技巧：[话术]
- 注意事项：[品类提醒]

═══════════════════════════════════════
```

3 个版本全部输出后，附上一段简要说明，帮助用户选择：

```
💡 版本选择建议：
- 想要高互动、拉近距离 → 选版本A（闺蜜分享型）
- 想要专业感、建立信任 → 选版本B（专业测评型）
- 想要走心共鸣、长尾流量 → 选版本C（故事叙事型）
```

## Execution Notes

- 正文中的产品体验和效果描述应基于用户提供的产品卖点合理生成，避免编造虚假功效
- 涉及美妆护肤类产品时，不使用"三天美白""一周祛斑"等夸大表述
- 涉及食品类产品时，提醒过敏原信息
- 涉及母婴类产品时，强调安全性，不替医生做健康建议
- 所有版本生成后一次性输出，不分段等待用户确认
