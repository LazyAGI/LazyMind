# 发布策略与品类适配指南

本文件提供小红书笔记的最佳发布时间建议和品类特定的创作技巧。

## 一、最佳发布时间

### 通用高峰时段

| 时段 | 推荐度 | 原因 |
|------|--------|------|
| 07:00-09:00 | ⭐⭐⭐ | 早通勤刷手机，适合轻松内容 |

### 按品类的最佳发布时间

#### 美妆护肤
- **最佳时间**：20:00-22:00（工作日）/ 10:00-12:00（周末）
- **原因**：晚间护肤时段用户代入感最强
- **附加建议**：换季前1-2周发布相关内容流量更高

#### 穿搭时尚
- **最佳时间**：07:00-09:00 / 17:00-19:00
- **原因**：出门前找穿搭灵感，下班后刷搭配
- **附加建议**：周一周五适合通勤穿搭，周末适合休闲穿搭

#### 美食零食
- **最佳时间**：11:00-13:00 / 17:00-19:00 / 21:00-22:00
- **原因**：饭点前后食欲最强，睡前嘴馋时段
- **附加建议**：办公室零食适合工作日午休发布

#### 家居收纳
- **最佳时间**：10:00-12:00（周末）/ 20:00-22:00
- **原因**：周末有时间整理，晚间规划家居改造
- **附加建议**：月末/季末发布收纳整理类内容更受欢迎

#### 数码电器
- **最佳时间**：12:00-14:00 / 20:00-22:00
- **原因**：午休研究产品，晚间深度对比
- **附加建议**：大促前2周发布测评/推荐类内容流量最高

#### 母婴育儿
- **最佳时间**：09:00-11:00 / 21:00-23:00
- **原因**：宝宝睡后妈妈刷手机的时间
- **附加建议**：避开接送孩子的时间段（15:00-16:00）

## 二、品类创作适配指南

### 美妆护肤

**核心要素：**
- 强调成分和功效，成分党用户多
- 前后对比是最大说服力，引导看图
- 肤质标注必须明确（干皮/油皮/混合/敏感）
- 价格敏感度高，平价产品更容易爆款

**避坑提醒：**
- 不夸大功效（如"三天美白"）
- 不贬低竞品拉踩
- 标注是否含敏感成分（酒精/香精等）

### 穿搭时尚

**核心要素：**
- 身高体重必须标注，方便参考
- 版型描述要具体（高腰/微喇/直筒/oversize）
- 搭配建议要可执行（搭什么鞋/什么上衣）
- 图片是第一生产力，文字辅助

**避坑提醒：**
- 不修图过度到失真
- 标注是否有滤镜色差
- 尺码建议要结合身高体重

### 美食零食

**核心要素：**
- 味道描述要具象（不只能说"好吃"）
- 热量/成分信息对减脂人群很重要
- 食用场景要具体（追剧/办公/早餐）
- 价格和规格要清楚

**避坑提醒：**
- 不过度修饰口感
- 过敏原信息要提醒（坚果/乳制品等）
- 不推荐三无产品

### 家居收纳

**核心要素：**
- 改造前后对比图是核心
- 尺寸和材质要标注
- 价格要透明，租房党对价格敏感
- 安装难度要说明

**避坑提醒：**
- 不推荐易碎/劣质产品
- 承重信息要提醒
- 租房适用性要标注（是否打孔/是否可拆卸）

### 数码电器

**核心要素：**
- 参数对比要专业但易懂
- 使用场景要具体（办公/游戏/学生）
- 性价比是核心决策因素
- 续航/散热等实际体验很重要

**避坑提醒：**
- 不只罗列参数，要有实际体验
- 不拉踩同类产品
- 标注购买渠道和保修信息

### 母婴育儿

**核心要素：**
- 安全性是第一位的
- 月龄/年龄要标注
- 成分/材质信息要透明
- 妈妈的真实感受最打动人

**避坑提醒：**
- 不推荐未经安全认证的产品
- 不制造育儿焦虑
- 不替医生做健康建议

## 三、发布建议输出模板

生成笔记时，发布建议按以下格式输出：

```
📋 发布建议
├── 推荐发布时间：[具体时段]
├── 推荐发布日期：[工作日/周末/大促节点]
├── 图片建议：[首图类型 + 图片数量]
├── 互动技巧：[评论引导话术]
└── 注意事项：[品类相关提醒]
```

### 图片建议通用原则

| 品类 | 首图建议 | 图片数量 |
|------|---------|---------|
| 美妆护肤 | 使用前后对比/产品摆拍 | 5-9张 |
| 穿搭时尚 | 全身穿搭/上身效果 | 3-6张 |
| 美食零食 | 实拍食物/包装展示 | 4-8张 |
| 家居收纳 | 改造前后对比/空间全貌 | 5-9张 |
| 数码电器 | 产品实拍/使用场景 | 4-7张 |
| 母婴育儿 | 使用场景/产品细节 | 4-8张 |
