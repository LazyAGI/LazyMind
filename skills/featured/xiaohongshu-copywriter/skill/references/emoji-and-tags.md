# Emoji 使用与话题标签推荐指南

本文件定义种草笔记中的 emoji 使用规范和话题标签推荐策略。

---

## 一、Emoji 使用规范

### 基本原则

1. **每段不超过 3 个 emoji**，避免视觉杂乱
2. **emoji 与内容相关**，不乱用无关表情
3. **标题末尾可加 1 个 emoji** 增强吸引力
4. **分隔线使用** `｜` 或 `·` 或 `—`，不用 `|`（半角竖线太细）

### 按品类的 Emoji 推荐库

#### 美妆护肤

- 步骤/流程：👇➡️🧴💄💆‍♀️

## 二、话题标签推荐策略

### 标签数量

每篇笔记推荐 **8-12 个标签**，结构如下：

| 标签类型 | 数量 | 作用 |
|---------|------|------|
| 大流量词（百万级浏览） | 2-3 个 | 抢曝光 |
| 中流量词（十万级浏览） | 3-4 个 | 精准触达 |
| 长尾词（精准匹配） | 3-5 个 | 高转化 |

### 长尾词生成规则

长尾词根据具体产品信息动态生成，格式为：

1. **品牌+品类**：如 `#XX面霜` `#XX防晒`
2. **成分+功效**：如 `#烟酰胺精华` `#积雪草修护`
3. **场景+产品**：如 `#军训防晒` `#早八妆容`
4. **人群+需求**：如 `#油皮控油` `#干皮补水`
5. **价格+品类**：如 `#百元面霜` `#50元以内口红`

### 标签排序规则

1. 最相关的标签放前面
2. 大流量词和中流量词交替排列
3. 长尾词放在最后
4. 标签之间用空格分隔，不用逗号

### 标签示例（以"某平价控油精华"为例）

```
#护肤 #好物推荐 #平价好物 #控油 #油皮护肤 #精华推荐 #XX精华 #烟酰胺精华 #早八护肤 #油皮控油 #百元精华 #学生党护肤
```

## 三、风格变体的 Emoji 与标签差异

| 版本 | Emoji 密度 | 标签侧重 |
|------|-----------|---------|
| 闺蜜分享型 | 中高（活泼） | 偏大流量词，吸引泛流量 |
| 专业测评型 | 低（克制） | 偏长尾词，精准触达成分党 |
| 故事叙事型 | 中（自然） | 大流量+长尾均衡，兼顾曝光与转化 |
