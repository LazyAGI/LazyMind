feat(orders)!: replace total with total_cents in requests and responses

Order responses no longer return total, a decimal amount in yuan, and
return total_cents, an integer amount in cents, instead. Order creation
requests no longer accept total and accept only total_cents.

Order id, order status fields and authentication are unchanged.

The migration guide and the request/response field tests are included in
this commit. The tests have not been run.

BREAKING CHANGE: total is removed from order responses and from order
creation requests; both sides use integer cents in total_cents. Callers
must rename the field and divide the value by 100 when rendering amounts.
Requests that still send total are no longer supported.

Refs: #391
