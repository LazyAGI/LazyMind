此前不存在 PDF 下载，因此用 feat 表达新增功能，而非修复既有缺陷。

修订 03
原始提交标题
chore: rename timeout to timeout_ms
修订后提交信息
feat(sdk)!: rename timeout to timeout_ms and use milliseconds

The public SDK configuration option timeout is removed and replaced by
timeout_ms, whose value is interpreted in milliseconds instead of
seconds. No compatibility field is retained. Callers must rename the
field and multiply their previous value by 1000.

BREAKING CHANGE: timeout is no longer accepted in the SDK
configuration. Use timeout_ms with the previous seconds value
multiplied by 1000.

Refs: #402

不是单纯改名：旧字段被移除且秒变毫秒，草案标出破坏性变更与 ×1000 迁移。

修订 04
原始提交标题
perf: make search 50% faster
修订后提交信息
refactor(search): rename variables and simplify structure

This is a naming and structure cleanup in the search function; intended
behavior is unchanged. No performance benchmark data was collected.

没有性能基准，移除“50% faster”；变量命名和结构整理使用 refactor。

展开本次修订的事实依据

1. 原标题：Updated login stuff!!!
事实：修复切换时区后登录会话误过期的问题，关联 #214；回归测试已编写但未运行。
2. 原标题：fix: support downloading invoices as PDF
事实：此前完全没有发票 PDF 下载，此次新增该功能，无已知兼容性破坏。
3. 原标题：chore: rename timeout to timeout_ms
事实：对外 SDK 配置删除 timeout，改为 timeout_ms；旧值是秒，新值是毫秒，不保留兼容字段。调用方需改字段名并把原值乘以 1000。关联 #402。
4. 原标题：perf: make search 50% faster
事实：只对搜索函数做了变量命名和结构整理，预期行为不变，没有性能基准数据。
