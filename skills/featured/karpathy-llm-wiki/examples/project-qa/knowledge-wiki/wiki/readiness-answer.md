# 9月16日能启动试点吗？

> 暂不建议按原计划启动：例外题验收未达标，跨境转人工提示尚未上线。

## Overview

总体正确率92%达到90%门槛，但例外题7/10=70%，未达到90%门槛；不能用总体分数代替例外验收。(→ [[acceptance-gates]])

## Key facts / claims

- 范围为20家商户，只覆盖退款进度与发票开具，跨境订单不在范围内。(→ [[pilot-scope]])
- 陈宁负责例外题复验。同一10题口径至少需9题正确，比当前多2题；这不是补充两道新题即可通过。(→ [[acceptance-gates]])
- 林舟提出的跨境转人工提示是试点前要求，而质量记录显示尚未上线；应补齐并验收，笔记未指定实现负责人。(→ [[pilot-scope]]) (→ [[acceptance-gates]])
- 计划9月16日起试点3天。连续15分钟错误率超过5%时关闭自动回答并转人工，由许禾执行。(→ [[operating-plan]])
