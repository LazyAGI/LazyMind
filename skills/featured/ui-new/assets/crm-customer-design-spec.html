UI 设计第三案例最终产出

客脉 CRM · 客户管理后台 UI 设计方案

面向销售团队日常使用的客户管理后台重设计。最终产出先给出页面结构、组件布局、视觉规范和关键交互说明，再展示完整的高保真 HTML 原型。

方案说明 + HTML UI

01. 设计目标

围绕销售团队高频查看、筛选、跟进和新增客户的工作流，提升专业感、信息密度和操作效率。

专业可信

采用深蓝品牌色、克制阴影与清晰层级，避免装饰化和廉价感。

高信息密度

单屏可读 10 条以上客户记录，状态、跟进时间和客户价值一眼定位。

操作清晰

跟进、新增客户等高频动作常驻可见，低频筛选和导出合理收纳。

桌面端优先

内容区适配大屏工作台，表格保持横向字段完整，必要时滚动兜底。

02. 组件布局与交互

把决策信息、筛选入口和执行动作组织成稳定的桌面工作台。

  • 统计卡：4 列等宽，展示客户总数、今日新增、待跟进、本月成交额。
  • 筛选区：状态 Tab 常驻，负责人、来源、标签、跟进时间使用下拉筛选。
  • 客户表格：客户、联系方式、来源、状态、负责人、下次跟进、价值和操作分列展示。
  • 状态系统：新客户蓝色、跟进中橙色、已成交绿色、已流失灰色、超期风险红色。
  • 行操作：Hover 时浮现跟进和编辑按钮，平时保持表格干净。
  • 多选：支持全选与选中计数，便于批量导出或批量分配。
  • 跟进抽屉：右侧滑出记录时间线，保留客户列表上下文。
  • 新增客户：居中弹窗承载两列表单，保存后 Toast 反馈。
