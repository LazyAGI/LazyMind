SKILL.md 草案

方法：结论先行会议纪要法 · 来源：《金字塔原理》章节

适用范围

  • 跨部门例会、评审会、需求澄清会的纪要整理

不适用范围

  • 不做会议纪要翻译、不做语音转写（依赖已有速记/录音）

输入要求

  • 会议速记或录音文字稿；与会人角色；期望产出语言

执行流程

  • 提取核心决定，置顶为结论行
  • 按决定 / 待办 / 风险分组
  • 待办补全负责人与截止日期
  • 输出 Markdown 纪要并自检

质量检查

  • 结论可独立读懂；每条待办有 owner + 时间；无遗漏分歧
边界约束：仅整理用户提供的会议内容，不虚构未讨论的决定或数据。
