# 行业概览与产业链分析

## 1. 定义行业边界

先回答“包含什么、不包含什么”：

- 产品或服务边界
- 客户和使用场景
- 地理范围
- 上下游边界
- 替代品和邻近市场
- 历史数据与预测数据的时间区间

如果来源使用不同定义，分别保留，并选定一个主口径贯穿报告。

## 2. 划分细分市场

根据问题选择有解释力的维度：

- 产品或技术路线
- 客户类型
- 应用场景
- 价格带
- 销售渠道
- 地区
- 价值链环节

避免为了完整而无限细分。优先保留能够解释增长、利润池或竞争差异的维度。

## 3. 测量规模与增长

至少记录：基期规模、最新规模、历史增速、预测期和预测增速。对 CAGR 使用：

```text
CAGR = (期末值 / 期初值) ^ (1 / 年数) - 1
```

能获得多种估算时进行三角验证：

- 自上而下：宏观总量 × 行业渗透率或占比
- 自下而上：客户数量 × 使用量 × 平均价格
- 公司汇总：主要企业收入 ÷ 可解释的覆盖率

三种方法不必得到同一数字，但应能解释差异来源。

### 区分市场层级

- **TAM**：满足所定义需求的理论总市场；说明产品、地区和客户边界。
- **SAM**：在当前产品与服务能力下可覆盖的市场；写明从 TAM 排除的范围。
- **SOM**：在给定渠道、产能和竞争条件下可获得的市场；没有透明假设时不输出伪精确单点。

不得把不同来源的 TAM、SAM 和 SOM 放在同一趋势序列，也不得把预测 TAM 与历史收入直接比较。市场规模采用乘法模型时，逐项列出客户数、使用量、价格、渗透率等输入及来源；任一输入未核验时，将结果标为情景估算而非已核验事实。

### 分开历史与预测

- 历史值记录数据对应期间和是否为修订值。
- 预测值记录发布机构、预测起点、预测终点和方法。
- 只有至少两个同口径时点时才描述历史变化；单个时点不能使用“加速、放缓、修复或承压”。
- 多个规模来源无法统一时，展示口径区间和差异原因，不做简单平均。

## 4. 绘制价值链

对每个关键环节说明：

| 项目 | 分析内容 |
|---|---|
| 输入 | 原材料、技术、人才、资本或渠道 |
| 参与者 | 代表性企业和角色 |
| 商业模式 | 收费方式、收入确认和客户关系 |
| 成本结构 | 固定成本、变动成本和主要敏感项 |
| 利润池 | 哪些环节获得更高利润及原因 |
| 控制点 | 标准、渠道、数据、品牌、产能或牌照 |
| 议价关系 | 上下游集中度和切换成本 |

必要时使用 Mermaid 流程图表示价值链，但图后必须配文字解释。

利润池判断至少绑定一种可验证证据：分环节毛利或营业利润、单位经济性、议价能力、稀缺控制点或现金转化。只有参与者数量或收入规模时，不直接推断利润池。

## 5. 分析增长驱动

按可验证机制拆解驱动因素：

- 需求量增长
- 渗透率提升或替代
- 价格或产品结构变化
- 政策和监管变化
- 技术进步和成本下降
- 供给扩张或瓶颈缓解
- 人口、收入和行为变化

对每个驱动写清“变量变化 → 传导路径 → 受益环节 → 可观测指标”。

同时记录反证和制约条件。政策发布、技术出现或客户表态本身不等于需求已经兑现；需要订单、使用量、价格、产能、渗透率或财务指标等后续证据确认传导。

## 6. 分析周期与风险

识别行业所处阶段：导入、成长、成熟、整合或衰退。区分结构性增长和周期性反弹。

至少覆盖：

- 需求和库存周期
- 价格与产能周期
- 监管、贸易和地缘风险
- 技术替代和产品淘汰
- 资本强度及融资风险
- 客户集中度和渠道依赖

## 7. 输出要求

按用户的研究目的选择必要部分，不为了套模板扩展无关内容。普通行业全景专题优先形成：行业边界与阶段、可信的市场或政策信号、价值链与代表参与者、主要机会与风险、未来跟踪信号和证据缺口。每个关键数字附数据日期和直接来源。

只有来源能够支持且用户问题确实需要时，才增加 TAM/SAM/SOM、利润池或完整规模预测；不得为了填满这些栏目扩大检索、使用相邻市场数字或构造伪精确估算。缺少同口径时间序列时，保留单点信号和局限，不强行描述增长趋势。
