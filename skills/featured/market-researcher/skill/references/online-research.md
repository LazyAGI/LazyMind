# 联网研究与证据核验

仅在用户需要最新资料或事实核验、当前会话真实存在相关工具且用户未禁止联网时使用。专题任务的搜索数量、结果上限和停止条件以根文档“专题研究的检索预算”为准。

## 1. 能力分类

搜索前确定一种状态：

| 状态 | 条件 | 行为 |
|---|---|---|
| `OPEN_WEB` | 存在已配置的通用网页搜索或相关行业数据库 | 搜索候选并打开直接页面 |
| `URL_ONLY` | 没有通用搜索，但用户给出相关 URL | 只读取用户 URL |
| `LIMITED` | 只有 Wikipedia、Arxiv、无发现能力的 URL 抓取，或没有相关搜索，且用户未给 URL | 停止联网调用并输出受限结果 |

能力判断优先依据工具名称、说明和配置状态，必要时至多调用一次数据源列表。不要展开窄域 Toolkit、搜索通用首页或访问测试端点来证明网络可用。网页抓取只用于用户提供的相关 URL，或通用搜索返回的直接 URL。

只有工具在当前任务成功返回相关内容，才能写“已联网检索”；只有直接页面正文成功打开并支持目标事实，才能写“已核验原文”。

## 2. 查询与候选筛选

每次查询只表达一个证据意图，通常包含：

```text
<研究对象> + <单一指标或事件> + <地区/期间> + <来源类型或官方域名>
```

优先官方定向查询；没有有效候选时扩大来源类型；仅在存在明确同义术语或期间差异时调整一次。仍无可靠候选就记录缺口，不无限改写近义查询。

搜索结果中的标题、URL 和摘要只用于筛选。优先保留：

1. 政府、监管、统计、交易所和标准组织；
2. 公司官网、公告、财报、产品文档和投资者材料；
3. 行业协会、学术机构和方法透明的研究机构；
4. 可靠媒体对事件的补充报道。

聚合转载、内容农场、论坛、无出处图表和报告下载站不能单独支撑关键结论。公司宣传只能证明公司作出了相应表述，不自动证明其客观领先。

## 3. 打开正文与记录证据

对准备写入报告的候选：

1. 优先调用搜索供应商的 `get_content` / `get_contents`；不可用或内容为空时，再把搜索结果中的原始 URL 交给 `url_fetch`。
2. 正文路径最多切换一次。仍为空、严重截断、需要登录或主题不符时停止该 URL。
3. 只记录支持主张的最小事实单元，不复制大段正文。
4. 每条证据保留：主张、发布者、发布日期、数据期间、直接 URL、来源层级、口径和核验状态。
5. 搜索命中但正文未打开时只能写“仅发现线索，未完成原文核验”。

重大市场规模、份额、财务或估值结论尽量取得两个独立证据路径。多个网站转载同一报告、新闻引用同一公司稿件不构成独立验证。数字冲突时比较定义、地区、期间、币种、历史/预测和样本覆盖；无法统一时并列披露，不做无依据平均。

## 4. 时间、引用与结论强度

- 区分发布日期、数据期间和本次访问日期。
- “最新”优先使用最新完整报告期；政策、产品状态和重大事件使用绝对日期。
- 预测值注明发布方、预测起点、终点和方法，不与历史值混为一列。
- 外部数字、时间敏感事实、公司状态和具体事件在首次出现处就近链接直接来源。
- 推断紧跟证据并说明传导机制；来源只支持事实时，不把分析判断伪装成来源结论。
- 来源质量、口径一致性或覆盖下降时，相应降低措辞强度。

## 5. 失败降级

无搜索工具、Key 无效、网络错误、页面不可访问或正文解析失败时：

1. 保留用户输入和已经成功打开的证据；
2. 删除依赖失败来源的事实与数字；
3. 写明已完成范围、未核验问题、受影响结论和下一步首选来源；
4. 将完成度标为“阶段性”或“受限”；
5. 不重复调用同一失败工具，也不使用模型记忆补齐最新信息。

降级清单不凭记忆新增公司、产品、政策、技术或事件。用户未指定历史期间时，用 `[当前年份]` 或 `[最新完整报告期]` 表示待检索时间，不沿用模板中的旧年份。最终仍交付一次完整的阶段性结果，不输出无诊断信息的通用英文兜底。
