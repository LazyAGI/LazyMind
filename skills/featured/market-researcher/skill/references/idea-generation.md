# 候选标的生成

## 1. 从研究结论生成候选池

候选标的必须来自前序证据，不从热门榜单或单一价格信号直接生成。优先寻找：

- 位于高增长或高利润池环节的公司
- 拥有可验证壁垒且壁垒正在增强的公司
- 份额、产品组合、利润率或资本效率改善的公司
- 市场预期与可验证基本面之间存在差异的公司
- 具有明确催化剂且下行风险可描述的公司

同时纳入直接龙头、关键上游、渠道控制者和可能的替代者，避免只看最知名公司。

## 2. 设定硬性筛选条件

根据用户范围定义：上市市场、流动性、规模、地区、行业暴露比例、财务数据可得性和排除项。

无法满足关键条件的公司进入观察名单，不进入核心候选。

## 3. 先做分维度判断，再决定是否评分

默认不生成综合分和总排名。先分别判断：

| 维度 | 核心问题 |
|---|---|
| 行业与利润池 | 公司是否处于有吸引力的环节 |
| 竞争优势 | 壁垒是否有证据且可持续 |
| 基本面质量 | 增长、利润、现金流和资本效率如何 |
| 估值与预期 | 当前定价隐含什么预期，是否已反映优势 |
| 催化剂 | 哪些事件可能改变市场认知 |
| 风险 | 下行风险和证伪条件是什么 |
| 证据完整度 | 关键维度是否有同口径数据支撑 |

只有用户明确要求单一排序且核心维度有足够证据，或用户明确给定了受限排序口径/权重时，才使用评分框架。若证据不足，只给“按现有指标的分维度顺序”，并明确它不是综合投资排名。优先采用用户给定权重；自行设定权重时必须解释目的并进行敏感性说明。缺失维度标记 `N/A`，不得以零分、中性分或模型猜测填补，也不得为了产生确定排序而使用无依据的小数分。

当只有增长、毛利率和估值倍数等少量指标时，输出“经营质量画像”“估值位置”和“待验证事项”，不要把经营质量最高的公司直接排为最佳候选。

## 4. 建立投资论点卡

每个核心候选至少包括：

- 一句话论点
- 对应的行业驱动和利润池
- 可验证竞争优势
- 关键经营指标
- 估值位置及其口径
- 未来 6—24 个月潜在催化剂
- 三项主要风险
- 证伪条件
- 下一次需要跟踪的数据或事件

对催化剂和跟踪事件使用绝对日期或明确窗口，并区分已公告事件、媒体报道和本报告推断。所谓催化剂必须说明“事件 → 经营或预期变化 → 可观测验证指标”，仅有事件名称时不预测方向或幅度。

## 5. 区分候选类型

根据证据标注，而不是暗示确定收益：

- **核心候选**：行业、公司和估值证据较完整
- **观察候选**：逻辑合理但仍缺少关键验证
- **高风险候选**：潜在回报依赖少数高不确定假设
- **排除**：不满足硬条件或论点已被证伪

## 6. 防止常见偏差

- 不把“好公司”等同于“好价格”。
- 不把低估值自动解释为低估，检查结构性衰退和治理风险。
- 不只列支持证据，主动寻找证伪材料。
- 不使用短期技术信号替代基本面论点。
- 不把候选清单写成个性化买卖建议。
- 不为上行或下行情景补造具体阈值；缺少依据时使用定性触发条件。

## 7. 输出要求

交付候选池、筛选条件、分维度判断、核心论点卡、观察名单、排除原因和持续跟踪指标。只有满足评分条件时才交付评分表；任何总排序旁都必须展示权重、证据质量和关键不确定性。
