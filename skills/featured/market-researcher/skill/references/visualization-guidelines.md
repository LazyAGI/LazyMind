# 研究图表与可视化规范

图表用于压缩复杂关系或帮助比较，不用于装饰。定量图表必须忠实复现用户输入、已核验来源或确定性计算；不得使用文生图模型绘制定量图表、坐标轴、市场份额或财务数据。

## 1. 选择图表类型

| 研究问题 | 推荐形式 | 使用条件 |
|---|---|---|
| 产业链、传导路径 | Mermaid `flowchart` | 环节和连接关系有证据支持 |
| 市场规模或经营指标随时间变化 | Mermaid `xychart-beta` | 期间、单位和口径一致 |
| 构成或份额 | Mermaid `pie` | 分母和覆盖范围明确 |
| 竞争定位 | Mermaid `quadrantChart` | 两条轴定义清晰且坐标有依据 |
| 事件与催化剂 | Mermaid `timeline` | 事件日期已经核验 |
| 多公司多指标比较 | Markdown 表格优先 | 指标量纲不同或图形可能误导 |

不能满足条件时使用表格或文字，不强行制图。

## 2. 受控直出路径

以下条件全部满足时，直接输出固定格式 Mermaid，不调用 `run_script`：

- 只生成一个单序列 `xychart-beta` 折线图/柱状图，或一个简单 `pie` 构成图；
- 数据全部来自用户输入或本回合已核验来源，且已先写入邻近 Markdown 表格；
- 标签唯一，数值有限且无缺失；趋势图的期间、单位和口径一致，饼图没有负值且至少一个值大于零；
- 数据点不超过 12 个，不需要多序列、归一化、聚合、插值或坐标推导。

按照表格原顺序逐项替换模板中的占位符。不得沿用模板示例值，不得增加 y 轴范围、预测点、缺失值或排序。标题、轴标签和分类标签使用双引号；标签中有换行或 Mermaid 控制字符时，先做不改变含义的简化，无法安全简化则改用表格。

趋势图模板：

````text
```mermaid
xychart-beta
  title "<标题>"
  x-axis "<横轴含义>" ["<标签1>", "<标签2>"]
  y-axis "<单位>"
  line [<数值1>, <数值2>]
```
````

柱状图把最后一行的 `line` 改为 `bar`。构成图模板：

````text
```mermaid
pie showData
  title <标题>
  "<分类1>" : <数值1>
  "<分类2>" : <数值2>
```
````

直出 Mermaid 只是把允许数据转换成渲染语法。不要写“脚本计算”“脚本校验”或“已外部核验”，也不要展示执行过程。

## 3. 确定性图表脚本

象限图、结构化字段转换、超出受控直出限制的图表，或用户明确要求脚本校验时，才通过 `run_script` 执行 `scripts/build-mermaid-chart.py`。脚本只把已提供数据转换为 Mermaid 源码，不搜索资料、不推断缺失值、不生成图片文件。

优先使用重复的 `--point` 参数，避免把嵌套 JSON 放进工具参数导致转义失败。趋势图和饼图使用 `标签=数值`，象限图使用 `标签=x,y`。只有输入本来就是多字段结构化数组时才使用 `--data-json`，并在调用前确认整个工具参数是合法 JSON；两种输入方式不得混用。

工具参数中的 `args` 必须是 JSON 数组值，而不是看起来像数组的字符串：

```json
{"name":"market-researcher","rel_path":"scripts/build-mermaid-chart.py","args":["--chart","xy-line","--title","市场规模趋势","--point","2022=100","--point","2023=120"]}
```

以下写法无效，禁止提交：

```json
{"name":"market-researcher","rel_path":"scripts/build-mermaid-chart.py","args":"[\"--chart\",\"xy-line\"]"}
```

趋势折线示例：

```text
run_script(
  name="market-researcher",
  rel_path="scripts/build-mermaid-chart.py",
  args=[
    "--chart", "xy-line",
    "--title", "市场规模趋势",
    "--x-axis-label", "年份",
    "--y-axis-label", "亿元",
    "--point", "2022=100",
    "--point", "2023=120"
  ]
)
```

构成图示例：

```text
args=[
  "--chart", "pie",
  "--title", "已覆盖样本构成",
  "--point", "A=40",
  "--point", "B=60"
]
```

竞争象限示例：

```text
args=[
  "--chart", "quadrant",
  "--title", "竞争定位",
  "--x-axis-label", "产品广度",
  "--y-axis-label", "客户深度",
  "--point", "A=0.7,0.8"
]
```

象限坐标必须由用户、已核验来源或明确展示的方法提供，并处于 0—1；脚本不会自动归一化。没有依据时改用战略分组表，不编造坐标。

同一图表任务最多调用一次 `run_script`。出现 `parameters error` 或参数类型错误后立即停止；不得改 Skill 名称、改脚本路径、增加 `allow_unsafe`、调用 `--help` 或重复相同参数。只有工具返回 `status: ok` 时才复制其 `mermaid` 字段。

## 4. 数据完整性

- 图表标题、轴标签、单位、期间和覆盖范围必须明确。
- 图中每个数据点必须能追溯到邻近表格或引用。
- 不混合历史值、预测值、不同币种、不同地区或不同统计口径。
- 饼图数值不必机械等于 100，但必须说明它表示完整市场、已覆盖样本还是其他分母。
- 缺失值不补零；缺失数据留在表格中标记 `N/A`，并从图中排除。
- 保留输入顺序。需要排序时，先说明排序方向和依据。

## 5. 图表解释

每张图后使用 1—3 句话回答：

1. 图中直接观察到了什么；
2. 哪些比较受口径或样本限制；
3. 哪些解释属于推断，需要什么额外证据。

封闭数据小样本只能描述数值、顺序和边界，不把视觉上的同向变化解释为相关性、因果或市场定价。

## 6. 渲染与降级

- LazyMind 能渲染 Mermaid 时，直接输出完整的 `mermaid` 代码块。
- 受控直出时，先输出同源 Markdown 表格，再输出固定模板生成的 Mermaid；两者必须逐项一致。
- 脚本成功时复制其 `mermaid` 字段，不手工改动数字或标签。
- 脚本失败后不重试。若数据仍满足受控直出全部条件，可以改走固定模板；否则只输出同源 Markdown 表格。
- Mermaid 渲染失败、语法不适合或数据条件不足时，只输出同源 Markdown 表格，不声称图表已生成。
- 用户明确要求封面或概念插图，且当前会话存在可用的图片生成工具时，可以生成非数据插图；插图失败不得影响研究报告。
- 当前没有演示文稿工具时，只输出逐页演示大纲，不把 Mermaid 或图片冒充 PPT 文件。

## 7. 最终检查

- [ ] 定量图表未调用文生图模型。
- [ ] 图表数据与邻近表格逐项一致。
- [ ] 单位、期间、数据日期和覆盖范围齐全。
- [ ] 图表没有补造缺失值、坐标或市场份额。
- [ ] 受控直出只用于单序列趋势/柱状图或简单构成图，且没有错误声称脚本已执行。
- [ ] 同一图表脚本至多调用一次，参数错误后没有重试或改用 `--help` 探测。
- [ ] 图后解释区分直接观察、推断和限制。
- [ ] 没有声称不存在的图片、附件或 PPT 已生成。
