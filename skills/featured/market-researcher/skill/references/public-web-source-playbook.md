# LazyMind 公开网页来源手册

仅当当前会话已经提供并成功调用通用网页搜索时读取本手册。它用于平替 WorkBuddy 的公开网页发现与原文取证，不用于模拟 NeoData、WeStock 或其他结构化金融数据库。

## 1. 工具映射

LazyMind 的 `web_search` 工具组会从 `WebSearchToolkit` 中选择已配置的搜索供应商。具体函数名可能随供应商变化，但执行语义保持一致：

1. 使用当前可用供应商的 `search` 方法发现候选页面。
2. 搜索结果中的标题、URL 和摘要只用于筛选，不作为已核验证据。
3. 对入选候选优先使用同一供应商的 `get_content` 或 `get_contents` 读取正文。
4. 如果上述正文方法不可用、返回空内容或明显缺页，再用 `url_fetch` 抓取搜索结果返回的原始 URL。
5. 两种正文路径均失败时，把该来源标为“仅发现线索，未完成原文核验”，不得引用摘要中的数字。

不要依赖具体供应商名称，也不要把 Wikipedia、Arxiv、网页抓取或知识库搜索描述成通用网页搜索。

## 2. 把研究问题拆成单一搜索意图

每次 `search` 只回答一个证据问题。查询通常由以下部分组成：

```text
<研究对象> + <单一指标或事件> + <地区> + <目标期间> + <来源类型或官方域名>
```

行业定义、市场规模、份额、公司财务、监管变化和近期事件应分别调用。不得把公司清单、多个不相关指标或多个地区拼进同一个查询。

对一个证据问题按以下顺序推进：

1. **官方定向查询**：加入监管机构、政府统计、交易所、公司披露或行业协会等来源提示。
2. **扩大来源类型**：官方查询无有效结果时，移除过窄域名，保留指标、地区、期间和来源类型。
3. **口径变体查询**：仅在存在明确同义术语、财年表达或行业边界差异时调整一次术语或期间。
4. 仍没有可靠候选时停止该证据问题，记录缺口；不要无限改写近义查询，也不要打开偏题页面证明工具可用。

## 3. 官方来源地图与便携查询

以下域名用于构造定向查询，不代表穷尽清单。应根据研究地区选择，不要机械搜索无关市场。

| 证据问题 | 首选来源 | 便携查询形态 |
|---|---|---|
| 中国宏观与统计口径 | 政府、国家统计及主管部门 | `"<对象>" "<指标>" site:gov.cn` 或匹配的主管部门域名 |
| 中国上市公司披露 | 巨潮资讯、交易所、公司投资者关系页面 | `"<公司全称>" "<报告期>" 年度报告 site:cninfo.com.cn` |
| 香港上市公司披露 | 港交所披露平台、公司投资者关系页面 | `"<公司全称>" annual report site:hkexnews.hk` |
| 美国上市公司披露 | SEC EDGAR、公司投资者关系页面 | `"<公司法定名称>" 10-K site:sec.gov` |
| 监管与政策变化 | 发布政策的监管或主管机构 | `"<政策主题>" "<地区>" site:<官方域名>` |
| 行业定义、标准和供需 | 行业协会、标准组织、政府或学术机构 | `"<行业>" "<指标>" "<目标期间>" <来源类型>` |
| 公司经营与产品状态 | 公司公告、财报、投资者材料 | `"<公司全称>" "<指标或产品>" investor relations` |
| 近期重大事件 | 监管/公司原始公告，可靠媒体作补充 | `"<对象>" "<事件>" "<绝对日期或期间>"` |

搜索供应商支持原生域名过滤时可以使用，但 Skill 不依赖该参数；查询中的 `site:` 提示是跨供应商的默认方案。搜索结果仍须检查真实域名，不能仅凭查询包含 `site:` 就认定结果来自官方来源。

## 4. 候选筛选与正文抓取

打开页面前先检查标题、域名、发布日期和摘要是否与证据问题匹配。优先保留：

- 直接发布原始数据、公告、报告或政策的页面；
- 期间、地区和统计边界与研究问题一致的材料；
- 有明确作者、发布机构和方法说明的二手研究；
- 能被正文读取并可提供直接 URL 的页面或文件。

下列候选仅作线索或直接排除：

- 搜索结果页、聚合转载、无出处图表和内容农场；
- 地区、期间、公司主体或行业定义不匹配的页面；
- 只引用另一来源但没有提供额外核验的转载；
- 无法读取正文且关键主张只存在于搜索摘要中的页面。

需要打开多个候选时，先筛选再调用 `get_contents`；不要为了提高调用数量批量抓取全部结果。正文为空、截断或错误时可以切换一次抓取路径，仍失败则停止该 URL。

## 5. 最小证据闭环

每个进入结论的外部主张至少记录：主张、发布者、发布日期、数据期间、直接 URL、来源层级、统计口径和核验状态。

- **市场规模、份额、增速和预测**：必须打开含数字和口径的直接页面或报告；重大结论尽量增加独立来源。只有单一来源时明确局限，不用多个转载冒充交叉验证。
- **公司财务与估值输入**：优先公司披露或交易所文件，统一报告期、币种和单位；行情日期不明确时不计算当前估值。
- **监管或公司事件**：先核验原始公告和绝对日期；事件影响属于分析推断，不能伪装成公告原文结论。
- **竞争格局**：参与者识别可用多来源汇总，但份额和排序必须满足统一边界与期间，不能根据搜索排名推断市场排名。

## 6. 完成度判断

| 状态 | 判定 |
|---|---|
| 完整 | 核心证据问题均有直接页面支撑，关键数字与时间敏感事实已核验，主要口径冲突已处理 |
| 阶段性 | 通用搜索可用，但部分直接页面不可读、关键口径缺失，或结构化行情与估值输入不足 |
| 受限 | 只有窄域搜索、用户给定少量 URL，或通用搜索没有返回与主题相关的有效候选 |

公开网页搜索不能补齐实时行情、K 线、资金流、筹码、完整一致的历史序列、付费研报全文或卖方一致预期。用户要求这些内容而当前没有相应结构化工具时，明确省略或列为待补数据，不得从零散网页拼接出伪结构化结果。
