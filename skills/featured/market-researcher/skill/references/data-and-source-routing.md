# 数据与来源路由

## 1. 先建立证据矩阵

为每个研究问题记录以下字段：

| 字段 | 要求 |
|---|---|
| 问题 | 需要回答的具体问题 |
| 指标或证据 | 支撑结论所需的事实、指标或案例 |
| 首选来源 | 最接近原始事实的来源类型 |
| 备用来源 | 首选来源不可用时的替代来源 |
| 数据日期 | 数据对应期间，不是网页访问日期 |
| 发布日期 | 页面、公告或报告的发布日期 |
| 信息类型 | 用户输入、已核验来源、确定性计算、推断、情景假设或缺口 |
| 数值来源 | 用户输入位置、来源链接与日期，或计算输入与方法 |
| 状态 | 已验证、冲突、缺失或仅可推断 |

先完成矩阵，再开始大规模检索，避免只收集容易找到但无关的信息。

### 数值许可规则

业务数字、比例、倍数、评分、排名权重和情景阈值必须满足以下至少一项：

1. 用户在当前任务中明确提供；
2. 当前任务中从可靠来源核验，并记录来源与数据日期；
3. 根据已列出的输入执行确定性计算，并说明计算方法。

不满足时写成定性条件或 `[待设定]`。不要把常见经验值、行业惯例、示例数字或模型记忆伪装成当前研究事实。

### 封闭数据模式

当用户限制为“只依据所给数据”“不检索”或同等范围时：

- 把用户输入视为封闭数据集，不调用外部来源补齐空白。
- 只生成输入事实、确定性计算、逐列比较和数据缺口；除用户明确要求的定性情景外，不形成关系强度、因果或市场定价推断。
- 情景分析只使用定性触发条件或用户给定阈值，不创建客户占比、留存率、增长率、估值倍数等具体假设值。
- 不得一边添加假设，一边声称“未引入外部事实或假设”。

## 2. 来源优先级

按以下顺序选择来源；用户或系统指定的来源优先级高于这里的默认顺序：

1. 法律法规、监管机构、政府统计、中央银行和交易所。
2. 公司年报、季报、招股书、投资者演示、公告和电话会材料。
3. 行业协会、标准组织、学术论文和可信数据库。
4. 有清晰方法论的研究机构和咨询机构。
5. 可靠财经媒体和专业媒体。
6. 聚合网站、二手转载和观点性内容，只用于线索，不单独支撑关键数字。

对市场规模、市场份额、增速和预测尤其检查：定义、地区、币种、名义或实际值、统计年份、是否包含预测。

## 3. 工具能力检测与降级

只使用当前会话真实可用的工具，不假设 NeoData、WeStock、WebSearch 或其他特定名称存在。

先区分以下能力，不要把它们混为一谈：

- **网页搜索**：发现候选来源；通常需要搜索供应商配置。
- **网页抓取**：读取已知 URL；不能替代全网搜索。
- **结构化数据工具**：按其覆盖范围返回金融、宏观或行业数据。
- **用户资料**：由用户提供，默认只证明材料中写了什么，不等于外部交叉核验。

用户要求最新资料、完整开放研究或事实核验时，读取 `references/online-research.md`。网页搜索或抓取工具不可用时，不反复尝试，也不以模型记忆补齐；改为阶段性研究并列出待取证问题。

### LazyMind 第一阶段平替边界

当 `web_search` / `WebSearchToolkit` 已配置且能够返回相关候选时，它可以平替 WorkBuddy 的公开网页搜索与原文发现路径。使用供应商的 `search` 发现来源，再按 `references/public-web-source-playbook.md` 打开直接页面并建立证据闭环。

该路径不等于 NeoData 或 WeStock：普通网页搜索不能稳定提供实时行情、K 线、资金流、筹码、完整历史序列、付费研报全文或一致预期。没有结构化金融工具时，行业定义、政策、公司披露和公开统计仍可联网完成；依赖上述结构化数据的估值、技术分析和筛选必须省略、降级或明确列为待补数据。

### 宏观、利率和板块数据

1. 若存在已配置的结构化金融数据工具，优先查询并记录返回日期和口径。
2. 否则使用央行、统计部门、监管机构、交易所和行业协会的公开材料。
3. 若只有二手数据，至少寻找第二个独立来源，并降低结论强度。

### 公司财务与估值

1. 优先使用公司披露和交易所文件确认收入、利润、现金流、股本与净负债。
2. 行情和企业价值可以使用可靠市场数据工具，但必须记录价格日期。
3. 不混用不同日期的价格、股本和财务期间而不作说明。

### K 线、技术指标和筹码

这些内容不是完整行业研究的必需项。仅当用户明确要求且存在可信行情工具时执行：

- 记录证券代码、市场、复权方式、时间区间和数据截止日。
- 将技术信号作为市场行为描述，不作为基本面事实或确定性预测。
- 缺少可靠数据时直接省略，并说明无法验证；不要模拟 WeStock 输出。

## 4. 时效性

读取当前日期，并根据问题选择检索精度：

- “今天、刚刚、最新事件”：精确到日。
- “近期、最新财报、当前估值”：精确到月或最新报告期。
- “趋势、周期、长期空间”：覆盖足够长的历史区间，并注明预测起点。

搜索结果的发布日期不等于数据日期。报告中优先写数据对应日期。

## 5. 交叉验证与冲突处理

出现不同数字时不要简单平均。依次检查：

1. 行业定义是否一致。
2. 地理范围和渠道范围是否一致。
3. 自然年、财年、滚动十二个月是否一致。
4. 名义值、实际值、含税或不含税是否一致。
5. 历史值、估算值和预测值是否一致。

无法统一时，同时保留区间和两种口径，并说明哪个更适合当前问题。

## 6. 引用规则

- 在数字或具体事实首次出现处就近附上来源。
- 链接到直接支撑结论的页面或文件，不链接搜索结果页。
- 对公司披露注明报告期，对市场数据注明价格日期。
- 对用户提供的数据标注“用户输入”，不要暗示已经外部核验。
- 对模型自行计算的结果标注“根据上述数据计算”。
- 对开放数据研究中的推断使用“表明、可能、意味着、在……条件下”等措辞；封闭数据小样本不得借这些措辞生成相关性、因果或市场定价解释。
- 对情景假设明确标注“假设”，并逐项说明其依据；没有依据时不得添加精确数值。
- 对外部数字、时间敏感事实、公司状态和具体事件逐项检查引用覆盖；关键结论不得只在报告末尾放一个笼统来源列表。
- 只有实际打开直接页面或文件后，才使用“已核验原文”；无法打开时标为“仅发现线索，未完成原文核验”。
