# 竞争格局分析

## 1. 确认竞争单元

不要默认所有公司都直接竞争。先确认它们是否服务相同客户、解决相同需求、处于相同价值链环节，并具有相近商业模式。

把参与者划分为：直接竞争者、替代方案、潜在进入者、上游控制者和下游渠道控制者。

## 2. 建立公司与战略分组

为主要参与者记录：

- 核心产品和客户
- 地区与渠道
- 收入来源和商业模式
- 规模、增速和盈利特征
- 技术、品牌、成本、渠道或监管优势
- 最近的重要战略变化

按最能解释竞争差异的两个维度进行战略分组，例如高端/大众、平台/垂直、直营/渠道、轻资产/重资产。两条轴必须能够从产品、客户、价格、渠道或经营数据中验证；缺少量化坐标时使用分组表，不把主观印象伪装成精确象限坐标。

## 3. 测量集中度

在口径一致时计算：

```text
CR3 = 前三家公司市场份额之和
CR5 = 前五家公司市场份额之和
HHI = 各公司市场份额百分数的平方和
```

若只能获得收入而非真实份额，可以构造“已覆盖样本份额”，但必须明确它不代表整个市场。

不要把不同年份、不同地区或不同产业链环节的数据放在同一份额表中比较。

只有至少两个同口径期间时才能写“获得或失去份额”。单个时点只能描述当前份额或已覆盖样本位置。公司声称“领先、第一、最大”时，记录其限定范围并寻找第三方或可复算数据，不直接改写成客观排名。

## 4. 评估竞争力量

分析以下机制，而不只给高、中、低标签：

- 现有竞争：价格、功能、渠道、营销、产能和服务竞争
- 新进入者：资本、认证、规模、数据、渠道和品牌门槛
- 替代品：性能、成本、便利性和客户转换条件
- 供应商：关键输入集中度、稀缺性和替代周期
- 客户：客户集中度、采购专业化、切换成本和议价能力

## 5. 识别可持续壁垒

对每项潜在壁垒寻找能够证伪的证据：

| 壁垒 | 支持证据 | 证伪信号 |
|---|---|---|
| 成本 | 单位成本、规模利用率、采购优势 | 竞品快速达到相同成本 |
| 技术 | 性能、专利、研发效率、迭代速度 | 技术快速商品化 |
| 网络或数据 | 双边网络、数据反馈、迁移成本 | 多归属普遍、迁移容易 |
| 品牌 | 溢价、复购、获客效率 | 促销依赖和份额流失 |
| 渠道 | 覆盖、独占关系、服务密度 | 新渠道削弱既有优势 |
| 监管 | 牌照、认证、合规积累 | 规则放宽或标准统一 |

壁垒必须同时具备：能够创造经济价值、竞争者难以复制、可持续时间足够长。

把“拥有技术、数据、品牌或渠道”视为待验证主张。必须继续回答该资源如何转化为价格、成本、留存、份额、现金流或资本效率，以及竞争者复制它需要什么条件。

## 6. 形成比较矩阵

至少比较：定位、规模、增长、盈利、产品差异、渠道、成本、技术、客户黏性、资本强度、风险和近期变化。

矩阵后的结论应回答：

1. 谁控制行业利润池，为什么？
2. 谁在获得或失去份额，证据是什么？
3. 哪些壁垒正在增强或削弱？
4. 未来竞争更可能发生在价格、产品、渠道还是生态？
5. 哪些变量会改变当前排序？

## 7. 输出要求

交付参与者地图、战略分组、份额或覆盖样本、竞争力量、壁垒证据与证伪信号、比较矩阵、变化趋势和待监控信号。区分公司宣传、第三方验证事实和本报告推断；缺少同口径时间序列时不输出份额趋势。
