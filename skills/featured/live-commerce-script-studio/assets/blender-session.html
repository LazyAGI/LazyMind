七步主播口播

1. 问题：下午想喝点鲜的，楼下买一杯不便宜，自己榨又不想把厨房收拾半天。

2. 引入：今天这台 400ml 的便携榨汁杯，就是给想把一杯饮品带出门的人准备的。

3. 卖点：杯体是商家提供的 400ml；USB-C 充电，商家标注充满约可打六杯；这两项都只按商品信息讲。

4. 信任：质检报告已挂在商品链接里，想确认的朋友可以自己点开看。

5. 价格：同一规格日常价 129 元一台，今晚直播价 89 元一台。

6. 紧迫：这个直播价只在今晚这场，库存数字还没盘点，所以不报数量。

7. 常问：能不能打冰、多久充满、售后怎么走？目前商家没有提供这些答案，现场应转为“请以链接说明和客服回复为准”。
