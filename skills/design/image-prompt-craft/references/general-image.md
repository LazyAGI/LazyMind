# 通用图片 Prompt

## 编译骨架

按需求取舍，不需要机械显示字段名：

```text
[画布、比例、最终用途]。
[主体在画面中的位置、尺度、视角、动作、与其他对象的关系]。
[环境中的具体对象、前中后景、视觉密度和留白]。
[一个主媒介或拍摄语法；摄影时给一个主镜头/机位和自然成像特征]。
[材质及表面行为]。[主光方向、软硬、色温、轮廓光或环境光]。
[主色、辅色、强调色及分布]。
[需要保持的一致性或准确性]。[最多 3–6 个针对性禁项]。
```

首句必须同时解决画布与构图，例如：`Landscape 16:9 editorial illustration, asymmetrical composition with the subject concentrated in the right third and quiet negative space on the left.` 比只在 API 参数里传比例更可靠。

## 可执行细节

- 主体：名称、数量、外形特征、姿态、朝向、表情、交互对象。
- 场景：选择能证明时间、地点和用途的具体对象，不罗列无关装饰。
- 构图：主体所在区域、景别、视线方向、层级、焦点、前中后景和留白用途。
- 摄影：只设一个主捕获语法，例如眼平视角、低位三分之四视角、俯拍、远处人群抓拍；镜头感和景深为构图服务。
- 插画：写清媒介、线条、形状语言、层次和纸张/印刷质感；不要只写艺术家或工作室名字。
- 材质：说明木、金属、玻璃、织物、纸张、皮肤或液体如何反光、透光、起伏或磨损。
- 光线：说明来源、方向、软硬和气氛，例如左侧窗光、柔和顶光、逆光轮廓、阴天漫射光。
- 色板：给 3–5 个自然语言颜色和各自职责，避免未经请求的通用蓝紫渐变。

## 文字策略

仅当文字必须由图片模型绘制时，逐条给出原文并放入双引号，说明层级、位置和可读性。精确长文、表格、数据标签或 PPT 正文优先交给后续排版层；图片模型负责无字底图或插画。

## 风格选择

从与用途最接近的一类选择一个主语法：

- 摄影：设备/机位、时间地点、自然缺陷、现实道具、可信材质。
- 商业产品：产品轮廓、台面/环境、材质微细节、主辅光、阴影、品牌边界。
- 编辑插画：形状语言、线条、层叠方式、印刷/纸张纹理、三层观看信息。
- 建筑空间：房间/建筑类型、视角、透视、材料、光线方向、负空间、真实阴影。
- 等距/技术视觉：固定视角、清楚的层级或组件、统一尺度、可读轮廓；需要精确标签时改用 SVG/排版层。
- 电影感：镜头景别、主体调度、场景深度、主光、空气透视和单一叙事瞬间。

## 常见失败修正

- “高级、专业、震撼” → 写出高级感来自哪种材料、光线、比例和克制程度。
- 主体太小 → 明确占画面比例、所在区域、景别和镜头距离。
- 画面太乱 → 指定唯一视觉焦点、减少道具，并给某一区域低密度留白。
- 风格漂移 → 删除冲突媒介，重复主媒介、形状语言和色板。
- 伪字/伪品牌 → 明确无可见品牌；非必要文字交给排版层。
