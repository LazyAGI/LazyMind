# 图片编辑与参考一致性

编辑 Prompt 先说改什么，再说锁定什么。不要把编辑请求重写成从零生成。

## 单图编辑合同

```text
Requested edit: [唯一需要发生的变化].
Edit scope: [准确对象、区域或全局属性].
Preserve: [身份、五官、身体、姿势、对象数量、构图、裁切、透视、背景、光线、阴影、材质、原文字和分辨率中未被用户要求改变的项].
Do not: [本次编辑最可能出现的 2–5 个附带变化].
```

局部编辑使用最小充分范围。全局调色或风格迁移也要保留物体数量、几何、布局、身份、姿势与机位，除非用户明确要求改变。

## 多参考图

给每张输入图编号并声明唯一职责，例如：

- `Image 1` 提供主体身份、形体与构图。
- `Image 2` 只提供色板、材质和光线风格。
- `Image 3` 提供必须准确保留的包装、图案或标志。

随后明确它们如何组合，并再次写出不得漂移的项。不能把所有参考图都笼统称为“风格参考”。

## 连续生成

角色、产品或场景跨图一致时，每轮都重复以下稳定锚点：身份轮廓、关键颜色、比例、标志性细节、服装/包装、主媒介。只把动作、镜头、环境或时间中用户允许变化的部分写成变量。
