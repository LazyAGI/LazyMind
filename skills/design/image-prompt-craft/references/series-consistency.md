# 系列一致性

把系列分成“固定 DNA”和“允许变量”。每条 Prompt 都必须完整重复固定 DNA，不能依赖上一条 Prompt 的上下文。

## 固定 DNA

- 主媒介或拍摄语法。
- 3–5 色色板及颜色职责。
- 光线方向、软硬与色温。
- 材质/纹理家族。
- 形状语言、边缘细节和空间深度。
- 一个可重复但可演化的视觉母题。
- PPT 系列还包括安全区表现、背景密度和禁字合同。

把它压缩成一段可逐字重复的 `series anchor`，避免同义改写导致漂移。

## 允许变量

- 当前页面/单图的主题隐喻。
- 焦点位置、镜头景别或运动方向。
- 母题在叙事中的状态：出现、展开、连接、转折、汇聚、收束。
- 少量强调色的占比和位置。

## 邻页差异

连续两张图至少在一个结构轴上明显不同，例如远近、疏密、单体/群体、水平/纵深、静止/流动。差异不能破坏固定 DNA。封面建立母题，内容页分解或推进，章节页放大转折，结尾页收束回声。

检查时遮住文案：若仍能看出它们属于同一系列且不是同一张图的换色版，才算通过。
